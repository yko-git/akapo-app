# 画面名
Profile

# 必須構成

## 1. 画面概要
このページは、ユーザーの自己紹介や経歴、スキルなどを表示する画面です。

## 2. URL
`/profile`

## 3. フォーム項目・表示要素
- 自己紹介文
- 言語スキル
- ツールスキル
- 経歴

## 4. 初期表示・デフォルト値
- 自己紹介文、言語スキル、ツールスキル、経歴の情報が初期表示されます。

## 5. ユーザー操作
- このページはユーザーが直接操作することはできません。
- 管理者側で情報を更新する必要があります。

## 6. バリデーション・エラーハンドリング
- 特になし

## 7. 画面遷移
- このページは単独の画面であり、他の画面から遷移することはできません。

## 8. 使用しているコンポーネント
- `Image`: Next.jsの画像表示コンポーネント
- `jost`: カスタムフォントコンポーネント

## 9. 使用しているHooks / Stores / API / Schema
- 特になし

## 10. 補足・制約
- 管理者側で自己紹介文、言語スキル、ツールスキル、経歴の情報を更新する必要があります。
- 画面レイアウトはモバイル/デスクトップで異なります。
