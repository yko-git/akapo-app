# 画面名
Profile

# 必須構成

## 1. 画面概要
このページは、ユーザーのプロフィールを表示する画面です。ユーザーの基本情報や経歴、スキルなどが確認できます。

## 2. ![screen](../docs/screens/profile.png)

## 3. URL
/profile

## 4. フォーム項目・表示要素
- ユーザー画像
- 住まい
- 自己紹介
- 言語
- 使用ツール
- 経歴

## 5. 初期表示・デフォルト値
- ユーザー画像は固定の画像が表示されます。
- その他の情報は、コンポーネントに直接記述された値が表示されます。

## 6. ユーザー操作
このページにはユーザー操作はありません。閲覧のみの画面です。

## 7. バリデーション・エラーハンドリング
バリデーションやエラーハンドリングは行われていません。

## 8. 画面遷移
このページから他の画面への遷移はありません。

## 9. 使用しているコンポーネント
- Image
- jost (フォントコンポーネント)

## 10. 使用しているHooks / Stores / API / Schema
特に使用していません。

## 11. 補足・制約
- 画面レイアウトはモバイル/デスクトップで異なります。
- 画像の読み込みは `loading="lazy"` が設定されています。
