# 画面名
ユーザーページ

# 必須構成

## 1. 画面概要
ユーザーのプロフィール情報を表示し、ログアウトや新規投稿の機能を提供するページです。

## 2. URL
/mypage

## 3. フォーム項目・表示要素
- ユーザーのアイコン画像
- ユーザーの名前
- ログアウトボタン
- 新規投稿ボタン
- ユーザーの投稿一覧

## 4. 初期表示・デフォルト値
- ユーザーのプロフィール情報が表示されます。
- ユーザーの投稿一覧が表示されます。

## 5. ユーザー操作
- ログアウトボタンをクリックするとログアウトし、ログインページ(/login)に遷移します。
- 新規投稿ボタンをクリックすると、新規投稿ページ(/posts/new)に遷移します。

## 6. バリデーション・エラーハンドリング
- ユーザープロフィールの取得に失敗した場合、エラーメッセージが表示されます。
- ユーザーの投稿の取得に失敗した場合、エラーメッセージが表示されます。

## 7. 画面遷移
- ログアウトボタンをクリックすると、ログインページ(/login)に遷移します。
- 新規投稿ボタンをクリックすると、新規投稿ページ(/posts/new)に遷移します。

## 8. 使用しているコンポーネント
- User
- Button
- StatusInfo
- Image
- UserPostListPage

## 9. 使用しているHooks / Stores / API / Schema
- useAuthStore
- usePostStore
- useRequireAuth
- fetchUserData
- fetchUserPosts
- UserProfile
- Post

## 10. 補足・制約
- ユーザーがログインしていない場合、このページにアクセスできません。
- ユーザープロフィールの取得や投稿の取得に失敗した場合、エラーメッセージが表示されます。
