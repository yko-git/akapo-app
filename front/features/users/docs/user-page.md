# 画面名
ユーザーページ

# 必須構成

## 1. 画面概要
ユーザーのマイページを表示する画面です。ユーザーの基本情報、投稿一覧、ログアウト機能などが含まれています。

## 2. ![screen](../docs/screens/user-page.png)

## 3. URL
/mypage

## 4. フォーム項目・表示要素
- ユーザーのアイコン画像
- ユーザー名
- ログアウトボタン
- 新規投稿ボタン
- ユーザーの投稿一覧

## 5. 初期表示・デフォルト値
- ユーザー情報の読み込み中は、ローディング表示が表示されます。
- ユーザー情報の取得に失敗した場合は、エラー表示が表示されます。

## 6. ユーザー操作
- ログアウトボタンをクリックするとログアウトし、ログイン画面に遷移します。
- 新規投稿ボタンをクリックすると、新規投稿画面に遷移します。
- ユーザーの投稿一覧から個別の投稿を選択すると、投稿詳細画面に遷移します。

## 7. バリデーション・エラーハンドリング
- ユーザー情報の取得に失敗した場合は、エラー表示が表示されます。

## 8. 画面遷移
- ログアウトボタンをクリックすると、ログイン画面に遷移します。
- 新規投稿ボタンをクリックすると、新規投稿画面に遷移します。
- ユーザーの投稿一覧から個別の投稿を選択すると、投稿詳細画面に遷移します。

## 9. 使用しているコンポーネント
- User
- Button
- StatusInfo
- Image
- UserPostListPage

## 10. 使用しているHooks / Stores / API / Schema
- useAuthStore
- usePostStore
- useRequireAuth
- fetchUserData
- fetchUserPosts

## 11. 補足・制約
- ユーザー情報の取得には認証が必要です。
- ユーザーの投稿一覧は、ユーザー情報の取得と同時に取得されます。
