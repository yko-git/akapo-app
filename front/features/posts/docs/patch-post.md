# 画面名
投稿編集

# 必須構成

## 1. 画面概要
投稿の編集を行う画面です。投稿の詳細情報を表示し、タイトル、本文、ステータス、カテゴリーの編集、画像の変更が可能です。

## 2. ![screen](../docs/screens/patch-post.png)

## 3. URL
/posts/new/[id]

## 4. フォーム項目・表示要素
- タイトル
- 本文
- ステータス
- カテゴリー
- 画像

## 5. 初期表示・デフォルト値
- 既存の投稿の情報が初期値として表示される
- 画像は既存の画像が表示される

## 6. ユーザー操作
- タイトル、本文、ステータス、カテゴリーの編集が可能
- 新しい画像の選択が可能
- 「投稿を編集」ボタンをクリックすると、投稿が更新される
- 「投稿一覧に戻る」ボタンをクリックすると、投稿一覧ページに遷移する

## 7. バリデーション・エラーハンドリング
- タイトルと本文は必須入力
- 画像ファイルは指定のファイル形式（PNG、JPEG、WEBP、SVG）のみ許可
- 入力エラーがある場合はエラーメッセージを表示
- 投稿の更新に失敗した場合はエラーメッセージを表示

## 8. 画面遷移
- 「投稿一覧に戻る」ボタンをクリックすると、投稿一覧ページ(/mypage)に遷移する

## 9. 使用しているコンポーネント
- PatchPost
- Button
- SelectBox
- StatusInfo

## 10. 使用しているHooks / Stores / API / Schema
- usePostForm
- patchPost
- uploadImage
- fetchPost
- NewPostSchema

## 11. 補足・制約
- 投稿の編集は、投稿の作成者のみが行えるものとする
- 画像の変更は任意で、変更しない場合は既存の画像が保持される
