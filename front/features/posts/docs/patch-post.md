# 画面名
投稿編集

# 必須構成

## 1. 画面概要
投稿の編集を行う画面です。投稿の詳細情報を表示し、タイトル、本文、ステータス、カテゴリーの編集、画像の変更が可能です。

## 2. ![screen](../../docs/screens/patch-post.png)

## 3. URL
/posts/new/[id]

## 4. フォーム項目・表示要素
- タイトル
- 本文
- ステータス
- カテゴリー
- 画像

## 5. 初期表示・デフォルト値
- 既存の投稿の情報が初期値として表示されます。
- ステータスのデフォルト値は「0」、カテゴリーのデフォルト値は「1」です。

## 6. ユーザー操作
- タイトル、本文、ステータス、カテゴリーを編集できます。
- 画像を変更できます。
- 「投稿を編集」ボタンをクリックすると、投稿が更新されます。
- 「投稿一覧に戻る」ボタンをクリックすると、投稿一覧ページに遷移します。

## 7. バリデーション・エラーハンドリング
- タイトルと本文は必須入力項目です。
- 画像ファイルは指定のファイル形式（PNG、JPEG、WEBP、SVG）のみ許可されます。
- 入力エラーが発生した場合、エラーメッセージが表示されます。
- 投稿の更新に失敗した場合、エラーメッセージが表示されます。

## 8. 画面遷移
- 「投稿一覧に戻る」ボタンをクリックすると、投稿一覧ページ（/）に遷移します。

## 9. 使用しているコンポーネント
- PatchPost
- Button
- SelectBox
- StatusInfo

## 10. 使用しているHooks / Stores / API / Schema
- usePostForm
- patchPost
- uploadImage
- fetchPost
- NewPost
- NewPostSchema

## 11. 補足・制約
- 既存の画像が存在する場合、新しい画像を選択しない限り、既存の画像が保持されます。
- 画像は圧縮処理が行われます。
