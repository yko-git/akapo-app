# 画面名
投稿詳細

# 必須構成

## 1. 画面概要
投稿の詳細情報を表示する画面です。投稿の内容、投稿者情報、コメント一覧、新規コメント投稿フォームが含まれています。

## 2. URL
`/posts/[id]`

## 3. フォーム項目・表示要素
- 投稿タイトル
- 投稿本文
- 投稿者名
- 投稿者アイコン
- 投稿日時
- カテゴリタグ一覧
- コメント一覧
- 新規コメント投稿フォーム

## 4. 初期表示・デフォルト値
- 投稿IDに対応する投稿データを取得し、画面に表示する
- コメント一覧は投稿IDに紐づくコメントデータを取得し、表示する
- 新規コメント投稿フォームは初期状態で空の状態で表示する

## 5. ユーザー操作
- 投稿者アイコンをクリックすると、投稿者の投稿一覧ページ(`/?user=投稿者名`)に遷移する
- 「BACK」リンクをクリックすると、投稿一覧ページ(`/`)に遷移する
- 新規コメント投稿フォームにコメントを入力し、送信ボタンをクリックすると、コメントが投稿される
- コメント一覧の各コメントに対して、返信ボタンをクリックすると、返信コメントを投稿できる

## 6. バリデーション・エラーハンドリング
- 新規コメント投稿フォームのバリデーション
  - 必須入力チェック
  - 最大文字数チェック
- 投稿データの取得や新規コメント投稿時のエラーハンドリング
  - エラー発生時は適切なエラー表示を行う

## 7. 画面遷移
- 投稿者アイコンをクリックすると、投稿者の投稿一覧ページ(`/?user=投稿者名`)に遷移する
- 「BACK」リンクをクリックすると、投稿一覧ページ(`/`)に遷移する

## 8. 使用しているコンポーネント
- `PostDetail`: 投稿の詳細情報を表示するメインコンポーネント
- `TagList`: 投稿のカテゴリタグ一覧を表示するコンポーネント
- `Photo`: 投稿の画像を表示するコンポーネント
- `StatusInfo`: 読み込み中やエラー時の状態を表示するコンポーネント
- `CommentsList`: 投稿に紐づくコメント一覧を表示するコンポーネント
- `CreateComment`: 新規コメント投稿フォームを表示するコンポーネント

## 9. 使用しているHooks / Stores / API / Schema
- Hooks
  - `useParams`: 現在のURLパラメータを取得するHook
  - `useRequireAuth`: ユーザー認証状態を確認するHook
- Stores
  - `usePostStore`: 投稿データの状態管理
  - `useCommentStore`: コメントデータの状態管理
- API
  - `fetchPost`: 投稿データを取得するAPI
  - `fetchComments`: コメントデータを取得するAPI
- Schema
  - `Post`: 投稿データのスキーマ
  - `Comment`: コメントデータのスキーマ

## 10. 補足・制約
- ユーザーが認証されていない場合は、ログインページ(`/login`)に遷移する
- 投稿データの取得や新規コメント投稿時にエラーが発生した場合は、適切なエラー表示を行う
