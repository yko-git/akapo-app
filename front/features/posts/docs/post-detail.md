# 必須構成

## 1. 画面概要
投稿の詳細情報を表示する画面です。投稿の内容、投稿者情報、コメント一覧、新規コメント投稿フォームが含まれています。

## 2. URL
`/posts/:id`

## 3. フォーム項目・表示要素
- 投稿画像
- 投稿タイトル
- 投稿カテゴリ
- 投稿日時
- 投稿者名
- 投稿者アイコン
- 投稿本文
- コメント一覧
- 新規コメント投稿フォーム

## 4. 初期表示・デフォルト値
- 投稿IDに対応する投稿データを取得し、画面に表示する
- コメント一覧は投稿IDに対応するコメントデータを取得し、表示する
- 新規コメント投稿フォームは初期状態で空の状態で表示する

## 5. ユーザー操作
- 投稿者アイコンをクリックすると、投稿者の投稿一覧ページに遷移する
- 「BACK」リンクをクリックすると、投稿一覧ページに遷移する
- 新規コメント投稿フォームにコメントを入力し、送信ボタンをクリックすると、新規コメントが投稿される

## 6. バリデーション・エラーハンドリング
- 新規コメント投稿フォームのバリデーションは行わない
- 投稿データの取得や新規コメントの投稿に失敗した場合は、エラーメッセージを表示する

## 7. 画面遷移
- 投稿者アイコンをクリックすると、投稿者の投稿一覧ページ(`/?user=:username`)に遷移する
- 「BACK」リンクをクリックすると、投稿一覧ページ(`/`)に遷移する

## 8. 使用しているコンポーネント
- `PostDetail`: 投稿の詳細情報を表示するメインコンポーネント
- `TagList`: 投稿のカテゴリを表示するコンポーネント
- `Photo`: 投稿の画像を表示するコンポーネント
- `StatusInfo`: 読み込み中やエラー時の状態を表示するコンポーネント
- `CommentsList`: 投稿に紐づくコメントの一覧を表示するコンポーネント
- `CreateComment`: 新規コメントを投稿するフォームコンポーネント

## 9. 使用しているHooks / Stores / API / Schema
- `usePostStore`: 投稿データの管理に使用
- `useCommentStore`: コメントデータの管理に使用
- `useRequireAuth`: ユーザー認証状態の確認に使用
- `fetchPost`: 投稿データの取得に使用
- `fetchComments`: コメントデータの取得に使用

## 10. 補足・制約
- 認証されていない場合は、ログインページ(`/login`)に遷移する
- 投稿データの取得や新規コメントの投稿に失敗した場合は、エラーメッセージを表示する
