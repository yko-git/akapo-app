# 画面名
投稿詳細

# 必須構成

## 1. 画面概要
この画面は、投稿の詳細情報を表示するためのものです。投稿の内容、投稿者情報、コメント一覧、新規コメント投稿フォームなどが表示されます。

## 2. ![screen](../docs/screens/post-detail.png)

## 3. URL
`/posts/:id`

## 4. フォーム項目・表示要素
- 投稿タイトル
- 投稿本文
- 投稿者名
- 投稿者アイコン
- 投稿カテゴリ
- 投稿日時
- コメント一覧
- 新規コメント投稿フォーム

## 5. 初期表示・デフォルト値
- 投稿IDに対応する投稿データを取得し、画面に表示する
- コメント一覧は投稿IDに対応するコメントデータを取得し、表示する
- 新規コメント投稿フォームは初期状態で空の状態で表示される

## 6. ユーザー操作
- 投稿者アイコンをクリックすると、その投稿者の投稿一覧ページ(`/?user=:name`)に遷移する
- 「BACK」リンクをクリックすると、投稿一覧ページ(`/`)に遷移する
- コメント一覧の下部にある新規コメント投稿フォームに入力し、送信ボタンをクリックすると、新しいコメントが投稿される

## 7. バリデーション・エラーハンドリング
- 新規コメント投稿フォームの入力値に問題がある場合は、エラーメッセージを表示する
- 投稿データの取得や新規コメントの投稿に失敗した場合は、エラー状態を表示する

## 8. 画面遷移
- 投稿者アイコンをクリックすると、投稿一覧ページ(`/?user=:name`)に遷移する
- 「BACK」リンクをクリックすると、投稿一覧ページ(`/`)に遷移する

## 9. 使用しているコンポーネント
- `PostDetail`: 投稿の詳細情報を表示するメインコンポーネント
- `TagList`: 投稿のカテゴリを表示するコンポーネント
- `Photo`: 投稿の画像を表示するコンポーネント
- `StatusInfo`: 読み込み中やエラー時の状態を表示するコンポーネント
- `CommentsList`: 投稿に紐づくコメントの一覧を表示するコンポーネント
- `CreateComment`: 新規コメントを投稿するためのフォームコンポーネント

## 10. 使用しているHooks / Stores / API / Schema
- `useParams`: Next.jsのルーティング情報を取得するためのHook
- `usePostStore`: 投稿データの状態管理に使用するStore
- `useCommentStore`: コメントデータの状態管理に使用するStore
- `useRequireAuth`: ユーザーの認証状態を確認するためのカスタムHook
- `fetchPost`: 投稿データを取得するためのAPI関数
- `fetchComments`: コメントデータを取得するためのAPI関数

## 11. 補足・制約
- 認証されていないユーザーがこのページにアクセスした場合、ログインページ(`/login`)に遷移する
- 投稿データの取得や新規コメントの投稿に失敗した場合は、エラー状態を表示する
