# 必須構成

## 1. 画面概要
- 投稿一覧を表示する画面です。
- 投稿の一覧を表示し、投稿の詳細ページへのリンクを提供します。
- 投稿にはカテゴリーやコメント数などの情報が表示されます。
- ユーザーフィルターやページネーションなどの機能を備えています。

## 2. URL
- `/posts`

## 3. フォーム項目・表示要素
- 投稿一覧
  - 投稿の画像
  - 投稿のタイトル
  - 投稿のカテゴリー
  - 投稿のコメント数
  - 投稿者の名前と画像
  - 投稿日
- フィルターナビゲーション
  - カテゴリーフィルター
  - ユーザーフィルター
- ページネーション

## 4. 初期表示・デフォルト値
- 認証済みユーザーのみ表示可能
- 最新の投稿が表示される
- 1ページあたり 12 件の投稿が表示される
- カテゴリーやユーザーフィルターは初期状態では適用されない

## 5. ユーザー操作
- 投稿の詳細ページへのリンクをクリックする
- カテゴリーフィルターを選択する
- ユーザーフィルターを選択する
- ページネーションを使ってページを切り替える

## 6. バリデーション・エラーハンドリング
- 投稿の取得に失敗した場合はエラーメッセージを表示する
- 投稿データがない場合は空の状態を表示する

## 7. 画面遷移
- 投稿の詳細ページ (`/posts/:id`) へ遷移する
- ログイン画面 (`/login`) へ遷移する (未認証の場合)

## 8. 使用しているコンポーネント
- `PostListPage`
- `FilterNav`
- `PostList`
- `StatusInfo`
- `PageNation`
- `PhotoList`
- `TagList`

## 9. 使用しているHooks / Stores / API / Schema
- Hooks
  - `useRequireAuth`
  - `useCategoryFilter`
  - `usePostsFilter`
  - `usePostsPage`
- Stores
  - `usePostStore`
- API
  - `fetchPosts`
  - `fetchComments`
- Schema
  - `Post`
  - `PostWithComments`

## 10. 補足・制約
- 認証済みユーザーのみ表示可能
- 1ページあたりの表示件数は 12 件
- カテゴリーやユーザーフィルターを使用した場合は全件取得してからクライアント側でフィルタリングを行う
- 新着コメントがある投稿には "NEW COMMENT" のラベルが表示される
