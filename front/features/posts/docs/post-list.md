# 画面名
投稿一覧

# 必須構成

## 1. 画面概要
ユーザーが投稿した記事の一覧を表示する画面です。投稿にはカテゴリーやコメント数などの情報が含まれており、ユーザーはこれらの情報を確認できます。また、ページネーションや投稿者別のフィルタリングなどの機能も提供されています。

## 2. URL
`/posts`

## 3. フォーム項目・表示要素
- 投稿一覧
  - 投稿のサムネイル画像
  - 投稿のタイトル
  - 投稿のカテゴリー
  - 投稿のコメント数
  - 投稿者のアイコンと名前
  - 投稿日時
- フィルターナビゲーション
  - カテゴリーフィルター
  - ユーザーフィルター
- ページネーション

## 4. 初期表示・デフォルト値
- 投稿一覧は最新の投稿から順に表示される
- カテゴリーやユーザーのフィルターは初期状態では適用されない
- ページネーションは1ページ目が初期表示される

## 5. ユーザー操作
- 投稿のサムネイル画像をクリックすると、その投稿の詳細ページに遷移する
- カテゴリーフィルターを選択すると、選択したカテゴリーの投稿のみが表示される
- ユーザーフィルターを選択すると、選択したユーザーの投稿のみが表示される
- ページネーションのボタンをクリックすると、該当のページの投稿が表示される

## 6. バリデーション・エラーハンドリング
- 投稿の取得に失敗した場合は、エラーメッセージを表示する
- 投稿データが存在しない場合は、空の状態を表示する

## 7. 画面遷移
- 投稿の詳細ページ(`/posts/:id`)に遷移できる
- ログイン画面(`/login`)に遷移できる

## 8. 使用しているコンポーネント
- `PostListPage`: 投稿一覧の表示を担当するメインコンポーネント
- `FilterNav`: カテゴリーとユーザーのフィルターを提供するコンポーネント
- `PostList`: 投稿一覧を表示するコンポーネント
- `StatusInfo`: 読み込み中やエラー時の状態を表示するコンポーネント
- `PageNation`: ページネーションを提供するコンポーネント
- `PhotoList`: 投稿のサムネイル画像を表示するコンポーネント
- `TagList`: 投稿のカテゴリーを表示するコンポーネント

## 9. 使用しているHooks / Stores / API / Schema
- Hooks
  - `useRequireAuth`: ユーザーの認証状態を管理するカスタムフック
  - `useCategoryFilter`: URLクエリからカテゴリーフィルターの状態を取得するフック
  - `usePostsFilter`: ユーザーフィルターの状態を管理するフック
  - `usePostsPage`: ページネーションの状態を管理するフック
- Stores
  - `usePostStore`: 投稿データの状態を管理するストア
- API
  - `fetchPosts`: 投稿データを取得するAPI
  - `fetchComments`: 投稿のコメントデータを取得するAPI
- Schema
  - `Post`: 投稿データのスキーマ
  - `PostWithComments`: 投稿データにコメント情報を追加したスキーマ

## 10. 補足・制約
- 認証されていないユーザーはログイン画面に遷移される
- カテゴリーやユーザーフィルターを適用した場合、ページネーションは表示されない
- 投稿データの取得に失敗した場合はエラーメッセージを表示する
