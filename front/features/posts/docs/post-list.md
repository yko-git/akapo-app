# 画面名
投稿一覧

# 必須構成

## 1. 画面概要
この画面は、ユーザーが投稿した記事の一覧を表示するページです。投稿にはカテゴリーやコメント数などの情報が含まれており、ユーザーはカテゴリーやユーザー名でフィルタリングすることができます。また、ページネーションによって投稿を分割して表示することができます。

## 2. ![screen](../../docs/screens/post-list.png)

## 3. URL
- `/posts`

## 4. フォーム項目・表示要素
- 投稿一覧
  - 投稿のサムネイル画像
  - 投稿のタイトル
  - 投稿のカテゴリー
  - 投稿のコメント数
  - 投稿者の名前とアイコン
  - 投稿日
  - 新着コメントフラグ
- フィルターナビゲーション
  - カテゴリーフィルター
  - ユーザーフィルター
- ページネーション

## 5. 初期表示・デフォルト値
- 初期表示は、全ての投稿を最新順に表示する
- カテゴリーやユーザーフィルターは初期表示では適用されない

## 6. ユーザー操作
- 投稿をクリックすると、投稿詳細ページに遷移する
- カテゴリーフィルターを選択すると、選択したカテゴリーの投稿のみ表示される
- ユーザーフィルターを選択すると、選択したユーザーの投稿のみ表示される
- ページネーションのボタンをクリックすると、次のページの投稿が表示される

## 7. バリデーション・エラーハンドリング
- 投稿の取得に失敗した場合は、エラーメッセージを表示する
- 投稿がない場合は、空の状態を表示する

## 8. 画面遷移
- 投稿をクリックすると、投稿詳細ページ(`/posts/:id`)に遷移する
- ユーザーフィルターのリンクをクリックすると、ユーザー投稿一覧ページ(`/?user=:userName`)に遷移する

## 9. 使用しているコンポーネント
- `PostListPage`: 投稿一覧ページのメインコンポーネント
- `FilterNav`: カテゴリーとユーザーのフィルターナビゲーション
- `PostList`: 投稿一覧を表示するコンポーネント
- `StatusInfo`: 読み込み中やエラー時の状態を表示するコンポーネント
- `PageNation`: ページネーションを表示するコンポーネント
- `PhotoList`: 投稿のサムネイル画像を表示するコンポーネント
- `TagList`: 投稿のカテゴリーを表示するコンポーネント

## 10. 使用しているHooks / Stores / API / Schema
- Hooks:
  - `useRequireAuth`: ユーザーの認証状態を管理するカスタムフック
  - `useCategoryFilter`: URLクエリからカテゴリーフィルターの状態を取得するフック
  - `usePostsFilter`: ユーザーフィルターの状態を管理するフック
  - `usePostsPage`: ページネーションの状態を管理するフック
- Store:
  - `usePostStore`: 投稿の状態を管理するストア
- API:
  - `fetchPosts`: 投稿の一覧を取得するAPI
  - `fetchComments`: 投稿のコメントを取得するAPI
- Schema:
  - `Post`: 投稿の型定義
  - `PostWithComments`: 投稿とコメントの情報を含む型定義

## 11. 補足・制約
- 認証されていないユーザーはログインページに遷移される
- カテゴリーやユーザーフィルターを適用した場合、ページネーションは表示されない
- 新着コメントフラグは、投稿日から24時間以内にコメントがあった場合に表示される
