# 画面名
投稿一覧

# 必須構成

## 1. 画面概要
この画面は、ユーザーが投稿した記事の一覧を表示するページです。投稿の詳細情報や、新着コメントの表示、カテゴリーやユーザーによるフィルタリング、ページネーションなどの機能が含まれています。

## 2. ![screen](../docs/screens/post-list.png)

## 3. URL
- `/posts`

## 4. フォーム項目・表示要素
- 投稿一覧
  - 投稿の画像
  - 投稿のタイトル
  - 投稿のカテゴリー
  - 投稿のコメント数
  - 投稿者の名前と画像
  - 投稿日時
- 投稿者名によるフィルター
- カテゴリーによるフィルター
- ページネーション

## 5. 初期表示・デフォルト値
- 初期表示は、最新の投稿を一覧で表示する
- フィルターは初期状態では設定されていない

## 6. ユーザー操作
- 投稿の詳細ページへ遷移する
- 投稿者名でフィルタリングする
- カテゴリーでフィルタリングする
- ページネーションで次のページの投稿を表示する

## 7. バリデーション・エラーハンドリング
- 投稿の取得に失敗した場合は、エラーメッセージを表示する
- 投稿がない場合は、空の状態を表示する

## 8. 画面遷移
- 投稿の詳細ページ(`/posts/:id`)に遷移する
- ログイン画面(`/login`)に遷移する

## 9. 使用しているコンポーネント
- `PostListPage`: 投稿一覧ページのメインコンポーネント
- `FilterNav`: 投稿者名とカテゴリーのフィルターナビゲーション
- `PostList`: 投稿一覧を表示するコンポーネント
- `StatusInfo`: 読み込み中、エラー、空の状態を表示するコンポーネント
- `PageNation`: ページネーションを表示するコンポーネント
- `PhotoList`: 投稿の画像を表示するコンポーネント
- `TagList`: 投稿のカテゴリーを表示するコンポーネント

## 10. 使用しているHooks / Stores / API / Schema
- Hooks:
  - `usePostStore`: 投稿の状態管理
  - `useCategoryFilter`: カテゴリーフィルターの状態管理
  - `usePostsFilter`: 投稿者名フィルターの状態管理
  - `usePostsPage`: ページネーションの状態管理
  - `useRequireAuth`: ユーザー認証状態の管理
- API:
  - `fetchPosts`: 投稿の一覧を取得する
  - `fetchComments`: 投稿のコメントを取得する
- Schema:
  - `Post`: 投稿の情報
  - `PostWithComments`: 投稿の情報とコメント情報を含むデータ

## 11. 補足・制約
- ユーザーがログインしていない場合は、ログイン画面に遷移する
- 投稿の取得に失敗した場合は、エラーメッセージを表示する
- 投稿がない場合は、空の状態を表示する
- カテゴリーやユーザーフィルターがある場合は、クライアント側でフィルタリングを行う
