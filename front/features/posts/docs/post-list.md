# 画面名
投稿一覧

# 必須構成

## 1. 画面概要
この画面は、ユーザーが投稿した記事の一覧を表示するページです。投稿にはカテゴリーやコメント数などの情報が含まれており、ユーザーはカテゴリーやユーザー名でフィルタリングすることができます。また、ページネーションによって投稿を分割して表示することができます。

## 2. ![screen](../../docs/screens/post-list.png)

## 3. URL
- `/posts`

## 4. フォーム項目・表示要素
- 投稿一覧
  - 投稿のサムネイル画像
  - 投稿のタイトル
  - 投稿のカテゴリー
  - 投稿のコメント数
  - 投稿者の名前とアイコン
  - 投稿日
- フィルターナビゲーション
  - カテゴリーフィルター
  - ユーザーフィルター
- ページネーション

## 5. 初期表示・デフォルト値
- 投稿一覧は、最新の投稿から順に表示されます。
- カテゴリーやユーザーフィルターは初期状態では設定されていません。
- ページネーションは、1ページあたり10件の投稿を表示します。

## 6. ユーザー操作
- 投稿のサムネイル画像をクリックすると、その投稿の詳細ページに遷移します。
- カテゴリーフィルターを選択すると、選択したカテゴリーに属する投稿のみが表示されます。
- ユーザーフィルターを選択すると、選択したユーザーの投稿のみが表示されます。
- ページネーションのボタンをクリックすると、次のページの投稿が表示されます。

## 7. バリデーション・エラーハンドリング
- 投稿の取得に失敗した場合は、エラーメッセージを表示します。
- 投稿データが存在しない場合は、その旨のメッセージを表示します。

## 8. 画面遷移
- 投稿の詳細ページ(`/posts/:id`)に遷移できます。
- ログイン画面(`/login`)に遷移できます。

## 9. 使用しているコンポーネント
- `PostListPage`: 投稿一覧ページのメインコンポーネント
- `FilterNav`: カテゴリーとユーザーのフィルターナビゲーション
- `PostList`: 投稿一覧を表示するコンポーネント
- `StatusInfo`: 読み込み中やエラー時の状態を表示するコンポーネント
- `PageNation`: ページネーションを表示するコンポーネント
- `PhotoList`: 投稿のサムネイル画像を表示するコンポーネント
- `TagList`: 投稿のカテゴリーを表示するコンポーネント

## 10. 使用しているHooks / Stores / API / Schema
- `usePostStore`: 投稿の状態を管理するストア
- `useCategoryFilter`: URLクエリからカテゴリーフィルターの状態を取得するフック
- `usePostsFilter`: ユーザーフィルターの状態を管理するフック
- `usePostsPage`: ページネーションの状態を管理するフック
- `useRequireAuth`: ユーザーの認証状態を管理するフック
- `fetchPosts`: 投稿の一覧を取得するAPI
- `fetchComments`: 投稿のコメントを取得するAPI
- `Post`: 投稿のスキーマ

## 11. 補足・制約
- ユーザーが認証されていない場合は、ログイン画面に遷移します。
- カテゴリーやユーザーフィルターを使用する場合は、全件取得してからクライアント側でフィルタリングを行います。
- 新しいコメントがある投稿には「NEW COMMENT」のラベルが表示されます。
