# 画面名
ログイン

# 必須構成

## 1. 画面概要
ユーザーがログインするための画面です。ログインIDとパスワードを入力し、ログインボタンをクリックすることで、ユーザーデータの取得と認証が行われます。

## 2. ![screen](../../docs/screens/login.png)

## 3. URL
/login

## 4. フォーム項目・表示要素
- ログインID (テキスト入力)
- パスワード (パスワード入力)
- ログインボタン

## 5. 初期表示・デフォルト値
- ログインID、パスワードの入力欄は空の状態で表示されます。

## 6. ユーザー操作
- ログインIDとパスワードを入力する
- ログインボタンをクリックする

## 7. バリデーション・エラーハンドリング
- ログインIDとパスワードは必須入力項目です。
- 入力値が不正な場合はエラーメッセージを表示します。
- ログイン処理中はボタンがdisabledになり、ログイン中であることを示すメッセージが表示されます。
- ログイン失敗時はエラーメッセージを表示します。

## 8. 画面遷移
- ログイン成功時は/mypage画面に遷移します。
- 新規アカウント登録ボタンをクリックすると/signup画面に遷移します。

## 9. 使用しているコンポーネント
- LoginPage
- LoginForm
- Button

## 10. 使用しているHooks / Stores / API / Schema
- useLoginForm
- useAuthStore
- createLogin API
- NewLogin Schema

## 11. 補足・制約
- ログイン・新規ユーザー登録は午前9時〜午後9時の間にご利用いただけます。
