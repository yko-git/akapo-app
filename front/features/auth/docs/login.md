# 画面名
ログイン

# 必須構成

## 1. 画面概要
ユーザーがログインするための画面です。ログインIDとパスワードを入力し、ログインボタンをクリックすることで、ユーザーデータの取得と認証が行われます。

## 2. ![screen](../docs/screens/login.png)

## 3. URL
/login

## 4. フォーム項目・表示要素
- ログインID (テキスト入力)
- パスワード (パスワード入力)
- ログインボタン

## 5. 初期表示・デフォルト値
- ログインID、パスワードの入力欄は空の状態で表示されます。

## 6. ユーザー操作
- ログインIDとパスワードを入力する
- ログインボタンをクリックする

## 7. バリデーション・エラーハンドリング
- ログインIDとパスワードは必須入力項目です。
- 入力値が不正な場合はエラーメッセージを表示します。
- ログイン処理に失敗した場合はエラーメッセージを表示します。

## 8. 画面遷移
- ログイン成功時は、ユーザーのマイページ(/mypage)に遷移します。
- 新規アカウント登録ページ(/signup)へのリンクが表示されます。

## 9. 使用しているコンポーネント
- LoginPage
- LoginForm
- Button

## 10. 使用しているHooks / Stores / API / Schema
- useLoginForm (カスタムフック)
- useAuthStore (ストア)
- createLogin (API)
- NewLogin (スキーマ)

## 11. 補足・制約
- ログイン可能時間は午前9時から午後9時までです。
