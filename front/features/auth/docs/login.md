# 画面名

ログイン

# 必須構成

## 1. 画面概要

ユーザーがログインするための画面です。ログインIDとパスワードを入力し、ログインボタンをクリックすることで、ユーザーデータの取得とログイン処理が行われます。

## 2. ![screen](../../docs/screens/login.png)

## 3. URL

/login

## 4. フォーム項目・表示要素

- ログインID
- パスワード
- ログインボタン
- 新規アカウント登録リンク

## 5. 初期表示・デフォルト値

- ログインIDとパスワードの入力フィールドは空の状態で表示されます。

## 6. ユーザー操作

1. ログインIDとパスワードを入力する
2. ログインボタンをクリックする
3. 新規アカウント登録リンクをクリックする

## 7. バリデーション・エラーハンドリング

- ログインIDとパスワードの入力は必須です。
- 入力値が不正な場合、エラーメッセージが表示されます。
- ログイン処理に失敗した場合、エラーメッセージが表示されます。

## 8. 画面遷移

- ログイン成功時は、/mypage に遷移します。
- 新規アカウント登録リンクをクリックすると、/signup に遷移します。

## 9. 使用しているコンポーネント

- LoginPage
- LoginForm
- Button

## 10. 使用しているHooks / Stores / API / Schema

- useLoginForm
- useAuthStore
- fetchUserData
- createLogin
- NewLogin
- NewLoginSchema

## 11. 補足・制約

- ログイン・新規ユーザー登録は午前9時〜午後9時の間にご利用いただけます。
