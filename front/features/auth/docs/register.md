# 画面名
新規ユーザー作成

# 必須構成

## 1. 画面概要
新規ユーザー登録を行うための画面です。ユーザーは自身のログインID、パスワード、アカウント名、アイコン画像を入力し、登録を行うことができます。

## 2. ![screen](../docs/screens/register.png)

## 3. URL
/signup

## 4. フォーム項目・表示要素
- ログインID
- パスワード
- アカウント名
- アイコン画像

## 5. 初期表示・デフォルト値
- ログインID、パスワード、アカウント名は空の状態で表示されます。
- アイコン画像は初期表示では表示されません。

## 6. ユーザー操作
- ログインID、パスワード、アカウント名を入力する
- アイコン画像をアップロードする
- 「登録する」ボタンをクリックする

## 7. バリデーション・エラーハンドリング
- ログインID、パスワード、アカウント名は必須入力項目です。
- ログインIDは一意である必要があります。
- パスワードは一定の複雑性を持つ必要があります。
- アイコン画像はサポートされているファイル形式である必要があります。
- エラーが発生した場合は、エラーメッセージを表示します。

## 8. 画面遷移
- 登録完了後は、ログイン画面(/login)に遷移します。

## 9. 使用しているコンポーネント
- CreateUser
- Button

## 10. 使用しているHooks / Stores / API / Schema
- useUserForm
- createUser API
- NewUser Schema

## 11. 補足・制約
- 画像サイズが大きい場合、登録完了まで時間がかかることがあるため、ユーザーに待機を促す表示がある。
- 登録時間中は「登録中...」と表示される。
