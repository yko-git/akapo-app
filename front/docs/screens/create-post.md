# 新規投稿ページの画面仕様

## 概要
- このページは新しい投稿を作成するためのページです。
- ユーザーは投稿のタイトル、本文、ステータス(下書き/公開)、カテゴリ、画像を入力して投稿を作成できます。

## 画面構成
1. **新しい投稿を作成**
   - タイトル: 投稿のタイトルを入力するテキストフィールドです。
   - 本文: 投稿の本文を入力するテキストエリアです。
   - ステータス: 下書き用/本番反映を選択するドロップダウンリストです。
   - カテゴリ: 複数のカテゴリを選択するドロップダウンリストです。
   - 画像: 画像ファイルをアップロードするファイル選択フィールドです。
   - 投稿する: 入力内容を投稿するボタンです。投稿中は「投稿送信中...」と表示されます。
   - 画像サイズ注意書き: 画像サイズが大きい場合、投稿完了までに時間がかかる可能性があることを示す注意書きです。

2. **投稿一覧に戻る**
   - 投稿一覧ページに遷移するボタンです。

## 機能
1. **新規投稿**
   - ユーザーが入力した情報を使って新しい投稿を作成します。
   - 画像ファイルは圧縮処理を行った上で投稿されます。
   - 投稿が完了すると、マイページに遷移します。
   - 投稿に失敗した場合はエラーメッセージを表示します。

2. **入力値チェック**
   - タイトルと本文は必須入力項目です。
   - 選択したカテゴリIDは数値型で保存されます。
   - 画像ファイルは指定のファイル形式とサイズ制限内である必要があります。

3. **認証チェック**
   - ユーザーが認証済みであることを確認してから画面を表示します。認証されていない場合は何も表示しません。
