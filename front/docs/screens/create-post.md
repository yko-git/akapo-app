# 画面名
投稿作成

# 必須構成

## 1. 画面概要
この画面は、ユーザーが新しい投稿を作成できる画面です。ユーザーは題名、本文、下書き/本番の状態、カテゴリー、画像を入力し、投稿を作成することができます。

## 2. URL
`/posts/new`

## 3. フォーム項目・表示要素
- 題名 (テキスト入力)
- 本文 (テキストエリア)
- 下書き/本番 (ドロップダウンリスト)
- カテゴリー (複数選択ドロップダウンリスト)
- 画像 (ファイル選択)
- 投稿ボタン

## 4. 初期表示・デフォルト値
- 題名、本文、下書き/本番の状態、カテゴリーは空の状態で表示される
- 画像は選択されていない状態で表示される

## 5. ユーザー操作
- ユーザーは題名、本文、下書き/本番の状態、カテゴリー、画像を入力する
- ユーザーは投稿ボタンをクリックすると、入力した内容で新しい投稿が作成される

## 6. バリデーション・エラーハンドリング
- 題名と本文は必須入力項目
- 画像ファイルは指定のサイズ以内である必要がある
- 入力内容に問題がある場合はエラーメッセージを表示する
- 投稿に失敗した場合はエラーメッセージを表示する

## 7. 画面遷移
- 投稿が完了すると、マイページ (`/mypage`) に遷移する
- 投稿一覧ページ (`/`) へのリンクが用意されている

## 8. 使用しているコンポーネント
- `Button`: 投稿ボタンを表示するためのコンポーネント
- `SelectBox`: 下書き/本番の状態とカテゴリーを選択するためのコンポーネント
- `ImagePreview`: 選択された画像のプレビューを表示するためのコンポーネント

## 9. 使用しているHooks / Stores
- `usePostForm`: 投稿フォームの状態管理と入力値のバリデーションを行うカスタムフック
- `useRequireAuth`: ユーザーの認証状態を確認するカスタムフック
- `useRouter`: ページ遷移を行うためのフック

## 10. 補足・制約
- 画像ファイルは指定のサイズ以内に圧縮されて投稿される
- 投稿完了までに時間がかかる場合があるため、ユーザーに待機を促すメッセージを表示する
