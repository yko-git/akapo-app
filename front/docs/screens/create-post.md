# 画面仕様書

## 画面概要
投稿の作成画面です。ユーザーは新しい投稿を作成し、画像を添付することができます。

## URL
`/posts/new`

## 使用コンポーネント
- `Button` コンポーネント
- `SelectBox` コンポーネント
- `usePostForm` フックス

## フォーム項目・表示要素
- **タイトル**
  - 投稿のタイトルを入力する
- **本文**
  - 投稿の本文を入力する
- **下書き用/本番反映**
  - 投稿の公開状態を選択する
- **カテゴリー**
  - 投稿のカテゴリーを選択する
- **画像**
  - 投稿に添付する画像を選択する
- **プレビュー**
  - 選択した画像のプレビューが表示される

## 初期表示・デフォルト値
- 特に設定されていないため、空の状態で表示される

## ユーザー操作
1. タイトル、本文、公開状態、カテゴリーを入力する
2. 画像を選択する
3. 「投稿する」ボタンをクリックする

## API連携
- `createPost` API を呼び出して、投稿を作成する

## バリデーション・エラーハンドリング
- タイトルと本文は必須入力項目
- 選択した画像は有効な画像ファイルかチェックされる
- 投稿に失敗した場合は、エラーメッセージがトーストで表示される

## 補足・制約
- コード上では、画像の圧縮処理が行われている
- 画像サイズが大きい場合、投稿完了までに時間がかかることがあるため、ユーザーに待機を促す表示がある
