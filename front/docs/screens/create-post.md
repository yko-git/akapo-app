# 画面仕様書

## 画面概要

投稿の新規作成画面です。ユーザーは新規の投稿を作成し、公開することができます。

## URL

/posts/new

## 使用コンポーネント

- `CreatePost` コンポーネント
- `Button` コンポーネント
- `SelectBox` コンポーネント

## フォーム項目・表示要素

- タイトル
- 本文
- 下書き/公開ステータス
- カテゴリ
- 画像

## 初期表示・デフォルト値

- 初期表示時は何も入力されていない状態
- 下書き/公開ステータスのデフォルトは「下書き」
- カテゴリのデフォルトは選択なし
- 画像のデフォルトはなし

## ユーザー操作

1. タイトル、本文を入力する
2. 下書き/公開ステータスを選択する
3. カテゴリを選択する
4. 画像をアップロードする
5. 「投稿する」ボタンをクリックする

## API連携

- `createPost` API を呼び出して、新規の投稿を作成する

## バリデーション・エラーハンドリング

- タイトルと本文は必須入力
- 画像アップロード時に、ファイルサイズ・ファイル形式のバリデーションを行う
- エラー発生時は `toast` で警告メッセージを表示する

## 補足・制約

- 画像ファイルが大きい場合、圧縮処理を行うため、投稿完了までに時間がかかることがある
