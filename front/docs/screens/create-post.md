# 画面仕様書

## 画面概要
投稿作成画面では、ユーザーが新規の投稿を作成することができます。タイトル、本文、公開ステータス、カテゴリ、画像の選択・アップロードが可能です。

## URL
- `/posts/new`

## 使用コンポーネント
- `CreatePost` コンポーネント
- `Button` コンポーネント
- `SelectBox` コンポーネント

## フォーム項目・表示要素
- タイトル (テキスト入力)
- 本文 (テキストエリア入力)
- 公開ステータス (ドロップダウン選択)
- カテゴリ (マルチ選択ドロップダウン)
- 画像 (ファイルアップロード)
- 投稿ボタン

## 初期表示・デフォルト値
- 公開ステータスのデフォルト値は `"draft"` (下書き)
- カテゴリのデフォルト値はなし
- 画像のプレビューは表示されない

## ユーザー操作
1. タイトル、本文を入力する
2. 公開ステータスを選択する
3. カテゴリを選択する
4. 画像ファイルをアップロードする
5. 投稿ボタンをクリックする

## API連携
- `createPost` 関数を呼び出して、新規の投稿を作成する
  - 画像ファイルはあらかじめ圧縮されてから送信される

## バリデーション・エラーハンドリング
- タイトルと本文は必須入力
- 画像ファイルのフォーマットが正しいかチェックする
- 投稿作成に失敗した場合はエラーメッセージを表示する

## 補足・制約
- 画像サイズが大きい場合、投稿完了までに時間がかかることがあるため、その旨をユーザーに伝えている
- 認証済みユーザーのみが投稿できる
