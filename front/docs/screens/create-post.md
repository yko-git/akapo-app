# 画面名
投稿作成

# 必須構成

## 1. 画面概要
新しい投稿を作成するための画面です。投稿のタイトル、本文、ステータス(下書き/本番)、カテゴリー、画像をフォームから入力し、投稿を行うことができます。

## 2. URL
/posts/new

## 3. フォーム項目・表示要素
- 題名 (テキスト入力)
- 本文 (テキストエリア)
- 下書き/本番 (ドロップダウンリスト)
- カテゴリー (複数選択ドロップダウンリスト)
- 画像 (ファイル選択)
- 投稿ボタン

## 4. 初期表示・デフォルト値
- 題名: 空
- 本文: 空
- 下書き/本番: 下書き
- カテゴリー: 1つ選択済み
- 画像: 選択されていない

## 5. ユーザー操作
- 題名、本文、下書き/本番、カテゴリーを入力する
- 画像ファイルを選択する
- 投稿ボタンをクリックする

## 6. バリデーション・エラーハンドリング
- 題名、本文は必須入力
- 画像ファイルは指定のサイズ以内である必要がある
- 入力エラーがある場合はエラーメッセージを表示する
- 投稿時にエラーが発生した場合はエラーメッセージを表示する

## 7. 画面遷移
- 投稿一覧ページ(/mypage)に遷移する

## 8. 使用しているコンポーネント
- Button
- SelectBox

## 9. 使用しているHooks / Stores
- usePostForm
- useRequireAuth
- useRouter

## 10. 補足・制約
- 画像サイズが大きい場合、投稿完了まで時間がかかることがある
- 認証が必要な機能のため、未ログイン時は何も表示しない
