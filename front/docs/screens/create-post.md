# 画面名
投稿作成

# 必須構成

## 1. 画面概要
新しい投稿を作成するための画面です。ユーザーは題名、本文、下書き/本番の状態、カテゴリー、画像を入力して投稿を作成できます。

## 2. URL
`/posts/new`

## 3. フォーム項目・表示要素
- 題名 (テキスト入力)
- 本文 (テキストエリア)
- 下書き/本番 (ドロップダウンリスト)
- カテゴリー (複数選択ドロップダウンリスト)
- 画像 (ファイル選択)
- 投稿ボタン

## 4. 初期表示・デフォルト値
- 題名: 空
- 本文: 空
- 下書き/本番: 下書き
- カテゴリー: 1つ選択済み
- 画像: 選択されていない

## 5. ユーザー操作
- 題名、本文、下書き/本番、カテゴリーを入力する
- 画像ファイルを選択する
- 投稿ボタンをクリックする

## 6. バリデーション・エラーハンドリング
- 題名と本文は必須入力
- 画像ファイルは必須
- 画像ファイルのサイズが大きい場合は圧縮して送信
- 入力エラーがある場合はエラーメッセージを表示
- 投稿に失敗した場合はエラーメッセージを表示

## 7. 画面遷移
- 投稿一覧ページ (`/`) にリンクしている

## 8. 使用しているコンポーネント
- `Button`
- `SelectBox`
- `CreatePost`

## 9. 使用しているHooks / Stores
- `usePostForm`
- `useRequireAuth`
- `useRouter`

## 10. 補足・制約
- 画像サイズが大きい場合、投稿完了まで時間がかかることがあるため、ユーザーに待機を促す
