# 新しい投稿を作成する画面の仕様

## 概要

- この画面は、新しい投稿を作成するためのものです。
- ユーザーは、タイトル、本文、ステータス、カテゴリ、画像を入力して投稿を作成できます。
- 投稿が完了すると、マイページに遷移します。

## 画面構成

1. **タイトル入力欄**
   - ユーザーがタイトルを入力できます。
   - バリデーションにより、入力が必須となっています。

2. **本文入力欄**
   - ユーザーが本文を入力できます。
   - バリデーションにより、入力が必須となっています。

3. **ステータス選択ボックス**
   - ユーザーが投稿のステータスを選択できます。
   - 選択肢は以下の通りです:
     - 下書き
     - 公開

4. **カテゴリ選択ボックス**
   - ユーザーが投稿のカテゴリを選択できます。
   - 複数のカテゴリを選択できます。
   - 選択肢は以下の通りです:
     - カテゴリA
     - カテゴリB
     - カテゴリC

5. **画像アップロード**
   - ユーザーが投稿に使用する画像をアップロードできます。
   - 画像はプレビューで確認できます。
   - 画像サイズが大きい場合は、投稿完了までに時間がかかることがあることが表示されます。

6. **投稿ボタン**
   - ユーザーが投稿内容を確認し、投稿ボタンを押すと投稿が完了します。
   - 投稿中は、ボタンにローディング表示が表示されます。

7. **戻るボタン**
   - ユーザーが投稿一覧ページに戻れます。

## 動作仕様

1. ユーザーがタイトル、本文、ステータス、カテゴリ、画像を入力し、投稿ボタンを押す。
2. 入力内容のバリデーションチェックが行われる。
3. 画像が選択されている場合は、画像の圧縮処理が行われる。
4. 投稿処理が行われ、投稿が完了すると、マイページに遷移する。
5. 投稿に失敗した場合は、エラーメッセージが表示される。
