# 画面名
投稿作成

# 必須構成

## 1. 画面概要
新しい投稿を作成するための画面です。ユーザーは題名、本文、下書き/本番ステータス、カテゴリー、画像を入力して投稿を作成できます。

## 2. URL
`/posts/new`

## 3. フォーム項目・表示要素
- 題名 (テキスト入力)
- 本文 (テキストエリア)
- 下書き/本番ステータス (ドロップダウンリスト)
- カテゴリー (複数選択ドロップダウンリスト)
- 画像 (ファイル選択)
- 投稿ボタン

## 4. 初期表示・デフォルト値
- 題名: 空
- 本文: 空
- 下書き/本番ステータス: 下書き
- カテゴリー: 1つ選択済み
- 画像: 選択されていない

## 5. ユーザー操作
- 題名、本文、下書き/本番ステータス、カテゴリーを入力する
- 画像ファイルを選択する
- 投稿ボタンをクリックする

## 6. バリデーション・エラーハンドリング
- 題名と本文は必須入力
- 画像ファイルは必須
- 画像ファイルのサイズが大きい場合は圧縮して送信
- 投稿に失敗した場合はエラーメッセージを表示

## 7. 画面遷移
- 投稿完了後、投稿一覧ページ(`/`)に遷移する

## 8. 使用しているコンポーネント
- `Button`: ボタンコンポーネント
- `SelectBox`: ドロップダウンリストコンポーネント

## 9. 使用しているHooks / Stores
- `usePostForm`: 投稿フォームのカスタムフック
- `useRequireAuth`: 認証状態を確認するフック
- `useRouter`: ページ遷移を行うフック

## 10. 補足・制約
- 画像サイズが大きい場合、投稿完了まで時間がかかることがあるため、ユーザーに待機を促す
- 認証状態が確認できるまでは何も表示しない
