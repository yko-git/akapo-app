# 画面名
投稿作成

## 1. 画面概要
ユーザーが新規の投稿を作成するための画面です。タイトル、本文、下書き/公開ステータス、カテゴリー、画像をアップロードできます。

## 2. URL
`/posts/new`

## 3. フォーム項目・表示要素
- タイトル (必須)
- 本文 (必須)
- 下書き/本番ステータス (必須、ドロップダウン)
- カテゴリー (必須、複数選択可能)
- 画像 (オプション、ファイルアップロード)
- 投稿ボタン

## 4. 初期表示・デフォルト値
- タイトル: 未入力
- 本文: 未入力
- 下書き/本番ステータス: 下書き
- カテゴリー: 未選択
- 画像: 未選択

## 5. ユーザー操作
- タイトルと本文を入力する
- 下書き/本番ステータスを選択する
- カテゴリーを選択する
- 画像をアップロードする
- 投稿ボタンをクリックする

## 6. バリデーション・エラーハンドリング
- タイトルと本文は必須入力項目
- カテゴリーは1つ以上選択する必要がある
- 画像ファイルのサイズや形式が不正な場合は、ユーザーに適切なエラーメッセージを表示する
- 投稿の際にエラーが発生した場合は、ユーザーに適切なエラーメッセージを表示する

## 7. 画面遷移
- 投稿完了後、ユーザーのマイページ(`/mypage`)に遷移する
- 「投稿一覧に戻る」ボタンをクリックすると、トップページ(`/`)に遷移する

## 8. 使用しているコンポーネント
- Button
- SelectBox
- ImageUpload

## 9. 使用しているHooks / Stores
- useRequireAuth
- usePostForm
- useRouter
- useImageUpload

## 10. 補足・制約
- 画像ファイルは圧縮処理を行い、サイズを小さくする
- 画像のアップロードに時間がかかる場合は、ユーザーに待機を促す
