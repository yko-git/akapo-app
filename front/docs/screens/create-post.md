以下は、実装コードの変更点を反映した画面仕様書です。

## 画面概要
投稿の作成画面です。ユーザーは、タイトル、本文、状態、カテゴリー、そして画像を入力して投稿を作成することができます。

## URL
/posts/new

## 使用コンポーネント
- `CreatePost`: 投稿の作成機能を提供するコンポーネント
- `Button`: ボタンコンポーネント
- `SelectBox`: ドロップダウンリストのコンポーネント
- `usePostForm`: 投稿フォームのバリデーションを行うカスタムフック
- `useRequireAuth`: ユーザー認証の状態を管理するカスタムフック
- `imageCompression`: 画像圧縮を行うためのライブラリ
- `validateImageFile`: 画像ファイルのバリデーションを行う関数

## フォーム項目・表示要素
1. **タイトル**: 投稿のタイトルを入力する
2. **本文**: 投稿の本文を入力する
3. **状態**: 「下書き用」「本番反映」から選択する
4. **カテゴリー**: 複数のカテゴリーを選択できる
5. **画像**: 投稿に添付する画像を選択する
6. **投稿ボタン**: 入力された情報で投稿を作成する

## 初期表示・デフォルト値
- コード上では、初期表示や初期値の設定は確認できませんでした。

## ユーザー操作
1. タイトル、本文、状態、カテゴリーを入力する
2. 画像を選択する
3. 「投稿する」ボタンをクリックする

## API連携
- `createPost` API関数を呼び出して、入力された情報で新規投稿を作成する

## バリデーション・エラーハンドリング
- タイトルと本文の入力必須チェックを行う
- 画像ファイルの拡張子とサイズチェックを行う
- エラー発生時には `react-hot-toast` を使ってエラーメッセージを表示する

## 補足・制約
- 画像サイズが大きい場合、投稿完了までに時間がかかることがあるため、ユーザーに注意書きがある

## 変更内容
1. `CreatePost` コンポーネントに以下の変更が加えられました:
   - `handleFileChange` 関数を追加し、ユーザーが画像を選択したときにプレビューを表示するようになりました。
   - `onSubmit` 関数を追加し、ユーザーが投稿する際に画像を圧縮し、`createPost` API 関数を呼び出して新規投稿を作成するようになりました。
   - `react-hook-form` を使用してフォームのバリデーションを行うようになりました。
   - `validateImageFile` 関数を使用して、選択された画像ファイルのバリデーションを行うようになりました。

2. `app/posts/new/[id]/page.tsx` ファイルが新しく追加されました。このファイルは投稿の編集機能を提供するページコンポーネントです。
