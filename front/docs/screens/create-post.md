# 画面仕様書

## 1. 画面概要（目的）
新しい投稿を作成するための画面です。ユーザーは投稿のタイトル、本文、ステータス、カテゴリー、画像を入力し、投稿を作成することができます。

## 2. URL
unknown

## 3. 使用しているコンポーネント
- `CreatePost`: 投稿作成のためのフォームを提供するコンポーネント
- `Button`: ボタンコンポーネント
- `SelectBox`: ドロップダウンリストを提供するコンポーネント

## 4. フォーム項目
### タイトル
- フィールド名: `title`
- 型: `string`
- 必須: はい
- バリデーションルール: なし

### 本文
- フィールド名: `body`
- 型: `string`
- 必須: はい
- バリデーションルール: なし

### ステータス
- フィールド名: `status`
- 型: `string`
- 必須: はい
- バリデーションルール: 
  - `statusList`から選択する

### カテゴリー
- フィールド名: `categoryIds`
- 型: `number[]`
- 必須: はい
- バリデーションルール:
  - `categories`から選択する

### 画像
- フィールド名: `file`
- 型: `File`
- 必須: いいえ
- バリデーションルール:
  - 画像ファイルのみ許可
  - 画像サイズが大きい場合は圧縮する

## 5. デフォルト値
- 特になし

## 6. ユーザー操作
1. タイトル、本文、ステータス、カテゴリーを入力する
2. 画像ファイルを選択する
3. 「投稿する」ボタンをクリックする

## 7. API 連携
- `createPost`: 投稿を作成するAPI

## 8. エラーハンドリング
- 投稿に失敗した場合はエラーメッセージを表示する

## 9. 備考／制約事項
- 画像サイズが大きい場合は圧縮して投稿する
- 認証済みのユーザーのみ投稿できる
