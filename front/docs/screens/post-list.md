# 画面名
投稿一覧

# 必須構成

## 1. 画面概要
ユーザーが投稿した記事の一覧を表示する画面です。投稿にはカテゴリーやコメント数などの情報が含まれており、ユーザーはカテゴリーやユーザー名でフィルタリングできます。また、ページネーションにより複数ページの投稿を表示できます。

## 2. URL
`/posts`

## 3. フォーム項目・表示要素
- 投稿一覧
  - 投稿の画像
  - 投稿のタイトル
  - 投稿のカテゴリー
  - 投稿のコメント数
  - 投稿者の名前と画像
  - 投稿日
- フィルターナビゲーション
  - カテゴリーフィルター
  - ユーザーフィルター
- ページネーション

## 4. 初期表示・デフォルト値
- 投稿一覧は最新の投稿から順に表示される
- カテゴリーやユーザーフィルターは初期状態では設定されていない

## 5. ユーザー操作
- 投稿をクリックすると、その投稿の詳細ページに遷移する
- カテゴリーフィルターを選択すると、選択したカテゴリーの投稿のみ表示される
- ユーザーフィルターを選択すると、選択したユーザーの投稿のみ表示される
- ページネーションのボタンをクリックすると、次のページの投稿が表示される

## 6. バリデーション・エラーハンドリング
- 投稿の取得に失敗した場合は、エラーメッセージを表示する
- 投稿がない場合は、空の状態を表示する

## 7. 画面遷移
- 投稿の詳細ページ(`/posts/:id`)に遷移できる
- ログイン画面(`/login`)に遷移できる

## 8. 使用しているコンポーネント
- `PostListPage`: 投稿一覧ページのメインコンポーネント
- `FilterNav`: カテゴリーとユーザーのフィルターナビゲーション
- `PostList`: 投稿一覧を表示するコンポーネント
- `StatusInfo`: 読み込み中やエラー時の状態を表示するコンポーネント
- `PageNation`: ページネーションを表示するコンポーネント
- `PhotoList`: 投稿の画像を表示するコンポーネント
- `TagList`: 投稿のカテゴリーを表示するコンポーネント
- `Image`: 投稿者のアイコン画像を表示するコンポーネント

## 9. 使用しているHooks / Stores / API / Schema
- Hooks
  - `useRequireAuth`: ログイン状態を管理するカスタムフック
  - `useCategoryFilter`: URLクエリからカテゴリーフィルターの状態を取得するフック
  - `usePostsFilter`: ユーザーフィルターの状態を管理するフック
  - `usePostsPage`: ページネーションの状態を管理するフック
- Store
  - `usePostStore`: 投稿の状態を管理するストア
- API
  - `fetchPosts`: 投稿の一覧を取得するAPI
  - `fetchComments`: 投稿のコメントを取得するAPI
- Schema
  - `Post`: 投稿の情報を表す型
  - `PostWithComments`: 投稿情報とコメント情報を含む型

## 10. 補足・制約
- ログインしていない場合は、ログイン画面に遷移する
- カテゴリーやユーザーフィルターを使用する場合は、全件取得してからクライアント側でフィルタリングを行う
- 新着コメントがある投稿には「NEW COMMENT」のラベルが表示される
