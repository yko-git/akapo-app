# 画面名
投稿一覧

# 必須構成

## 1. 画面概要
ユーザーが投稿した記事の一覧を表示する画面です。投稿の詳細情報や、新着コメントの表示、カテゴリーフィルターなどの機能を提供します。

## 2. URL
`/posts`

## 3. フォーム項目・表示要素
- 投稿の写真
- 投稿のタイトル
- 投稿者の名前とアイコン
- 投稿日時
- 投稿のカテゴリー
- 投稿へのコメント数
- 新着コメントの表示

## 4. 初期表示・デフォルト値
- 投稿一覧は、投稿日時の降順で表示されます。
- カテゴリーフィルターは初期状態では適用されていません。

## 5. ユーザー操作
- 投稿の写真をクリックすると、その投稿の詳細ページに遷移します。
- カテゴリーフィルターを選択することで、選択したカテゴリーに属する投稿のみを表示できます。

## 6. バリデーション・エラーハンドリング
- 投稿の取得に失敗した場合は、エラーメッセージを表示します。
- 投稿データがない場合は、その旨のメッセージを表示します。

## 7. 画面遷移
- 投稿の写真をクリックすると、その投稿の詳細ページ(`/posts/:id`)に遷移します。
- ログインしていない場合は、ログインページ(`/login`)に遷移します。

## 8. 使用しているコンポーネント
- `FilterNav`: カテゴリーフィルターを提供するナビゲーションコンポーネント
- `PostList`: 投稿一覧を表示するコンポーネント
- `PhotoList`: 投稿の写真を表示するコンポーネント
- `TagList`: 投稿のカテゴリーを表示するコンポーネント
- `StatusInfo`: 読み込み中やエラー時のステータス情報を表示するコンポーネント
- `Image`: 投稿者のアイコンを表示するコンポーネント

## 9. 使用しているHooks / Stores / API / Schema
- `usePostStore`: 投稿データの管理に使用するストア
- `useRequireAuth`: ログイン状態の確認に使用するフック
- `useCategoryFilter`: URLクエリからカテゴリーフィルターの状態を取得するフック
- `fetchPosts`: 投稿データを取得するAPI
- `fetchComments`: 投稿のコメントデータを取得するAPI
- `Post`: 投稿データのスキーマ
- `PostWithComments`: 投稿データにコメント情報を追加したスキーマ

## 10. 補足・制約
- ログインしていない場合は、ログインページに遷移します。
- 投稿データの取得に失敗した場合は、エラーメッセージを表示します。
- 投稿データがない場合は、その旨のメッセージを表示します。
- 新着コメントの判定は、コメントの作成日時から24時間以内のものを対象としています。
