# 画面名
投稿一覧

# 必須構成

## 1. 画面概要
ユーザーが投稿した記事の一覧を表示する画面です。投稿にはカテゴリーやコメント数などの情報が含まれており、ユーザーはカテゴリーやユーザー名でフィルタリングできます。また、ページネーションにより複数ページの投稿を表示できます。

## 2. URL
- `/posts`

## 3. フォーム項目・表示要素
- 投稿一覧
  - 投稿のサムネイル画像
  - 投稿のタイトル
  - 投稿のカテゴリー
  - 投稿のコメント数
  - 投稿者のアイコンと名前
  - 投稿日時
- フィルターナビゲーション
  - カテゴリーフィルター
  - ユーザーフィルター
- ページネーション

## 4. 初期表示・デフォルト値
- 初期表示は最新の投稿一覧
- カテゴリーフィルターとユーザーフィルターはデフォルトでオフ

## 5. ユーザー操作
- 投稿一覧の投稿をクリックすると、投稿詳細ページに遷移する
- カテゴリーフィルターを選択すると、選択したカテゴリーの投稿のみ表示される
- ユーザーフィルターを選択すると、選択したユーザーの投稿のみ表示される
- ページネーションのボタンをクリックすると、次のページの投稿一覧を表示する

## 6. バリデーション・エラーハンドリング
- 投稿の取得に失敗した場合は、エラーメッセージを表示する
- 投稿データがない場合は、空の状態を表示する

## 7. 画面遷移
- 投稿一覧から投稿詳細ページに遷移する
- 投稿一覧からログイン画面に遷移する

## 8. 使用しているコンポーネント
- `PostListPage`: 投稿一覧ページのメインコンポーネント
- `FilterNav`: カテゴリーとユーザーのフィルターナビゲーション
- `PostList`: 投稿一覧を表示するコンポーネント
- `StatusInfo`: 読み込み中やエラー時の状態を表示するコンポーネント
- `PageNation`: ページネーションを表示するコンポーネント
- `PhotoList`: 投稿のサムネイル画像を表示するコンポーネント
- `TagList`: 投稿のカテゴリーを表示するコンポーネント

## 9. 使用しているHooks / Stores / API / Schema
- Hooks:
  - `useRequireAuth`: ユーザーの認証状態を確認するフック
  - `useCategoryFilter`: URLクエリからカテゴリーフィルターの状態を取得するフック
  - `usePostsFilter`: ユーザーフィルターの状態を管理するフック
  - `usePostsPage`: ページネーションの状態を管理するフック
- Stores:
  - `usePostStore`: 投稿データの状態を管理するストア
- API:
  - `fetchPosts`: 投稿データを取得するAPI
  - `fetchComments`: 投稿のコメントデータを取得するAPI
- Schema:
  - `PostWithComments`: 投稿データにコメント情報を追加したデータ型

## 10. 補足・制約
- ユーザーの認証状態を確認し、未認証の場合はログイン画面に遷移する
- 投稿データの取得に失敗した場合はエラーメッセージを表示する
- 投稿データがない場合は空の状態を表示する
- カテゴリーフィルターとユーザーフィルターは排他的に適用される
