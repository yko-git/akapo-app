# 画面名
投稿一覧

# 必須構成

## 1. 画面概要
- 投稿された記事の一覧を表示する画面です。
- 投稿の詳細ページへのリンクが設置されています。
- 投稿に関するメタ情報(カテゴリ、コメント数、新着コメントの有無など)が表示されます。

## 2. URL
- `/posts`

## 3. フォーム項目・表示要素
- 投稿のサムネイル画像
- 投稿のタイトル
- 投稿者のアイコンと名前
- 投稿日時
- 投稿のカテゴリ
- 投稿へのコメント数
- 新着コメントの有無

## 4. 初期表示・デフォルト値
- 投稿一覧は、投稿日時の降順で表示されます。
- 投稿がない場合は、「投稿がありません」と表示されます。
- 投稿の取得中は、ローディング表示が表示されます。
- 投稿の取得に失敗した場合は、エラーメッセージが表示されます。

## 5. ユーザー操作
- 投稿のサムネイル画像をクリックすると、その投稿の詳細ページに遷移します。

## 6. バリデーション・エラーハンドリング
- 投稿の取得に失敗した場合は、エラーメッセージが表示されます。

## 7. 画面遷移
- 投稿のサムネイル画像をクリックすると、その投稿の詳細ページ(`/posts/:id`)に遷移します。
- ログインしていない場合は、ログインページ(`/login`)に遷移します。

## 8. 使用しているコンポーネント
- `PostList`: 投稿一覧を表示するコンポーネント
- `PhotoList`: 投稿のサムネイル画像を表示するコンポーネント
- `TagList`: 投稿のカテゴリを表示するコンポーネント
- `StatusInfo`: 投稿の取得状態(ローディング、エラー、空)を表示するコンポーネント
- `Image`: 投稿者のアイコンを表示するコンポーネント

## 9. 使用しているHooks / Stores / API / Schema
- `usePostStore`: 投稿の状態を管理するストア
- `useRequireAuth`: ログイン状態を確認するフック
- `fetchPosts`: 投稿一覧を取得するAPI
- `fetchComments`: 投稿のコメントを取得するAPI
- `Post`: 投稿の型定義
- `PostWithComments`: 投稿とコメントの情報を含む型定義

## 10. 補足・制約
- ログインしていない場合は、ログインページに遷移します。
- 投稿の取得に失敗した場合は、エラーメッセージが表示されます。
- 投稿がない場合は、「投稿がありません」と表示されます。
- 投稿の取得中は、ローディング表示が表示されます。
