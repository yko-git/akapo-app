# 画面名
投稿一覧

# 必須構成

## 1. 画面概要
- 投稿一覧を表示する画面です。
- 投稿の写真、タイトル、ユーザー情報、コメント数などの情報が表示されます。
- 新着コメントがある投稿には「NEW COMMENT」のラベルが表示されます。

## 2. URL
- `/posts`

## 3. フォーム項目・表示要素
- 投稿の写真
- 投稿のタイトル
- 投稿のカテゴリ
- 投稿のコメント数
- 投稿者のアイコンと名前
- 投稿日時

## 4. 初期表示・デフォルト値
- 投稿一覧が日付の新しい順に表示されます。
- 投稿データがない場合は「データがありません」と表示されます。
- 投稿データの取得中は「ロード中」と表示されます。
- 投稿データの取得に失敗した場合は「サービスが利用できません」と表示されます。

## 5. ユーザー操作
- 投稿の写真をクリックすると、その投稿の詳細ページ(`/posts/:id`)に遷移します。

## 6. バリデーション・エラーハンドリング
- 特になし

## 7. 画面遷移
- 投稿の写真をクリックすると、その投稿の詳細ページ(`/posts/:id`)に遷移します。

## 8. 使用しているコンポーネント
- `PostList`: 投稿一覧を表示するメインのコンポーネントです。
- `PhotoList`: 投稿の写真を表示するコンポーネントです。
- `TagList`: 投稿のカテゴリを表示するコンポーネントです。
- `StatusInfo`: 投稿データの状態(ロード中、データなし、エラー)を表示するコンポーネントです。
- `Image`: 投稿者のアイコンを表示するコンポーネントです。

## 9. 使用しているHooks / Stores
- `usePostStore`: 投稿データの管理に使用しているStoreです。
- `useRequireAuth`: ユーザーの認証状態を確認するHookです。

## 10. 補足・制約
- 投稿の取得には認証が必要です。認証されていない場合は、ログインページ(`/login`)に遷移します。
- 投稿の取得に失敗した場合は、エラーメッセージを表示します。
