# 画面名
投稿一覧

# 必須構成

## 1. 画面概要
ユーザーが投稿した記事の一覧を表示する画面です。投稿にはカテゴリーやコメント数などの情報が含まれており、ユーザーはカテゴリーやユーザー名でフィルタリングできます。

## 2. URL
`/posts`

## 3. フォーム項目・表示要素
- 投稿一覧
  - 投稿の画像
  - 投稿のタイトル
  - 投稿のカテゴリー
  - 投稿のコメント数
  - 投稿者の名前と画像
  - 投稿日時
- フィルターナビゲーション
  - カテゴリーフィルター
  - ユーザーフィルター

## 4. 初期表示・デフォルト値
- 投稿一覧は日付の新しい順に表示される
- カテゴリーフィルターとユーザーフィルターはデフォルトでは適用されない

## 5. ユーザー操作
- 投稿の画像をクリックすると、その投稿の詳細ページに遷移する
- カテゴリーフィルターを選択すると、選択したカテゴリーの投稿のみが表示される
- ユーザーフィルターを選択すると、選択したユーザーの投稿のみが表示される

## 6. バリデーション・エラーハンドリング
- 投稿の取得に失敗した場合は、エラーメッセージを表示する
- 投稿データがない場合は、空の状態を表示する

## 7. 画面遷移
- 投稿の画像をクリックすると、その投稿の詳細ページ(`/posts/:id`)に遷移する
- ユーザーフィルターを選択すると、ユーザー名でフィルタリングされた投稿一覧に遷移する

## 8. 使用しているコンポーネント
- `PostListPage`: 投稿一覧の表示を担当するメインコンポーネント
- `FilterNav`: カテゴリーとユーザーのフィルターを提供するコンポーネント
- `PostList`: 投稿一覧を表示するコンポーネント
- `StatusInfo`: 読み込み中やエラー時の状態を表示するコンポーネント
- `PhotoList`: 投稿の画像を表示するコンポーネント
- `TagList`: 投稿のカテゴリーを表示するコンポーネント

## 9. 使用しているHooks / Stores / API / Schema
- Hooks:
  - `useRequireAuth`: ユーザーの認証状態を確認するフック
  - `useCategoryFilter`: URLクエリからカテゴリーフィルターの状態を取得するフック
  - `usePostsFilter`: ユーザーフィルターの状態を管理するフック
- Stores:
  - `usePostStore`: 投稿データの状態を管理するストア
- API:
  - `fetchPosts`: 投稿データを取得するAPI
  - `fetchComments`: 投稿のコメントデータを取得するAPI
- Schema:
  - `Post`: 投稿データのスキーマ
  - `PostWithComments`: 投稿データにコメント情報を追加したスキーマ

## 10. 補足・制約
- 認証されていないユーザーはこの画面にアクセスできず、ログイン画面に遷移される
- 投稿の取得に失敗した場合は、エラーメッセージを表示する
- 投稿データがない場合は、空の状態を表示する
