# 画面名
投稿一覧

# 必須構成

## 1. 画面概要
- 投稿された記事の一覧を表示する画面です。
- 投稿の詳細ページへのリンクが設置されています。
- 投稿に関するメタ情報(カテゴリ、コメント数、新着コメントの有無など)が表示されます。

## 2. URL
- `/posts`

## 3. フォーム項目・表示要素
- 投稿の写真
- 投稿のタイトル
- 投稿者の名前
- 投稿日
- 投稿のカテゴリ
- コメント数
- 新着コメントの有無

## 4. 初期表示・デフォルト値
- 投稿一覧は、投稿日時の降順で表示されます。
- 投稿データがない場合は、「投稿がありません」と表示されます。
- 投稿の取得中は、ローディング表示が行われます。
- 投稿の取得に失敗した場合は、エラーメッセージが表示されます。

## 5. ユーザー操作
- 投稿の写真をクリックすると、その投稿の詳細ページに遷移します。

## 6. バリデーション・エラーハンドリング
- 投稿の取得に失敗した場合は、エラーメッセージが表示されます。

## 7. 画面遷移
- 投稿の写真をクリックすると、その投稿の詳細ページ(`/posts/:id`)に遷移します。

## 8. 使用しているコンポーネント
- `PostList`: 投稿一覧を表示するメインコンポーネント
- `PhotoList`: 投稿の写真を表示するコンポーネント
- `TagList`: 投稿のカテゴリを表示するコンポーネント
- `StatusInfo`: 投稿の取得状態(ローディング、エラー、空)を表示するコンポーネント
- `Image`: 投稿者のアイコン画像を表示するコンポーネント

## 9. 使用しているHooks / Stores
- `usePostStore`: 投稿データの管理に使用するカスタムフック
- `useRequireAuth`: ユーザーの認証状態を確認するカスタムフック

## 10. 補足・制約
- 投稿の取得には認証が必要です。未認証ユーザーはログイン画面に遷移されます。
- 投稿の写真は、サーバーから取得したsignedURLを使用して表示しています。
- 新着コメントの判定は、コメントの作成日時から24時間以内のものを「新着」とみなしています。
