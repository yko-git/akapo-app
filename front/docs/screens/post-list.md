# 画面名
投稿一覧

# 必須構成

## 1. 画面概要
ユーザーが投稿した記事の一覧を表示する画面です。投稿にはカテゴリーやコメント数などの情報が含まれており、ユーザーはカテゴリーやユーザー名でフィルタリングできます。また、ページネーションにより複数ページの投稿を表示できます。

## 2. URL
`/posts`

## 3. フォーム項目・表示要素
- 投稿一覧
  - 投稿のサムネイル画像
  - 投稿のタイトル
  - 投稿のカテゴリー
  - 投稿のコメント数
  - 投稿者のアイコンと名前
  - 投稿日
  - 新着コメントフラグ
- フィルターナビゲーション
  - カテゴリーフィルター
  - ユーザーフィルター
- ページネーション

## 4. 初期表示・デフォルト値
- 初期表示は最新の投稿一覧
- カテゴリーやユーザーフィルターの初期値は空

## 5. ユーザー操作
- 投稿一覧の表示
- カテゴリーフィルターの選択
- ユーザーフィルターの入力
- ページネーションによる次ページの表示

## 6. バリデーション・エラーハンドリング
- 投稿の取得に失敗した場合はエラーメッセージを表示
- 投稿がない場合は空の状態を表示

## 7. 画面遷移
- 投稿の詳細ページ(`/posts/:id`)に遷移できる
- ユーザーフィルターの場合は投稿一覧ページ(`/`)に遷移できる

## 8. 使用しているコンポーネント
- `PostListPage`: 投稿一覧ページのメインコンポーネント
- `FilterNav`: カテゴリーとユーザーのフィルターナビゲーション
- `PostList`: 投稿一覧を表示するコンポーネント
- `StatusInfo`: 読み込み中やエラー時の状態を表示するコンポーネント
- `PageNation`: ページネーションを表示するコンポーネント
- `PhotoList`: 投稿のサムネイル画像を表示するコンポーネント
- `TagList`: 投稿のカテゴリーを表示するコンポーネント

## 9. 使用しているHooks / Stores / API / Schema
- Hooks
  - `useRequireAuth`: ユーザーの認証状態を管理するフック
  - `useCategoryFilter`: URLクエリからカテゴリーフィルターの状態を取得するフック
  - `usePostsFilter`: ユーザーフィルターの状態を管理するフック
  - `usePostsPage`: ページネーションの状態を管理するフック
- Stores
  - `usePostStore`: 投稿の状態を管理するストア
- API
  - `fetchPosts`: 投稿一覧を取得するAPI
  - `fetchComments`: 投稿のコメントを取得するAPI
- Schema
  - `Post`: 投稿の型定義
  - `PostWithComments`: 投稿にコメント情報を追加した型定義

## 10. 補足・制約
- 認証されていないユーザーはログインページ(`/login`)に遷移される
- カテゴリーやユーザーフィルターを使用する場合は全件取得してからクライアント側でフィルタリングを行う
- 新着コメントフラグは投稿作成から24時間以内のコメントがある場合に表示される
