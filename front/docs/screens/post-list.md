# 画面名
投稿一覧

# 必須構成

## 1. 画面概要
- ユーザーが投稿した記事の一覧を表示する画面です。
- 投稿の詳細情報や、新着コメントの表示、カテゴリーフィルターなどの機能を提供します。

## 2. URL
- `/posts`

## 3. フォーム項目・表示要素
- 投稿一覧
  - 投稿の画像
  - 投稿のタイトル
  - 投稿者名
  - 投稿日時
  - カテゴリータグ
  - コメント数
  - 新着コメントフラグ
- カテゴリーフィルター

## 4. 初期表示・デフォルト値
- 投稿一覧は、投稿日時の降順で表示されます。
- カテゴリーフィルターは初期状態では全てのカテゴリーが選択された状態で表示されます。

## 5. ユーザー操作
- 投稿の画像をクリックすると、その投稿の詳細ページに遷移します。
- カテゴリーフィルターを選択すると、選択したカテゴリーの投稿のみが表示されます。

## 6. バリデーション・エラーハンドリング
- 投稿の取得に失敗した場合は、エラーメッセージを表示します。
- 投稿データが存在しない場合は、空の状態を表示します。

## 7. 画面遷移
- 投稿の詳細ページ (`/posts/:id`) に遷移できます。
- ログイン画面 (`/login`) に遷移できます。

## 8. 使用している コンポーネント
- `PostListPage`: 投稿一覧ページのメインコンポーネント
- `FilterNav`: カテゴリーフィルターのナビゲーションコンポーネント
- `PostList`: 投稿一覧を表示するコンポーネント
- `StatusInfo`: 読み込み中やエラー時の状態を表示するコンポーネント
- `PhotoList`: 投稿の画像を表示するコンポーネント
- `TagList`: 投稿のカテゴリータグを表示するコンポーネント
- `Image`: 投稿者のアイコン画像を表示するコンポーネント

## 9. 使用している Hooks / Stores / API / Schema
- `usePostStore`: 投稿データの管理に使用するストア
- `useCategoryFilter`: URLクエリからカテゴリーフィルターの状態を取得するフック
- `useRequireAuth`: ログイン状態を確認するフック
- `fetchPosts`: 投稿データを取得するAPI
- `fetchComments`: 投稿のコメントデータを取得するAPI
- `Post`: 投稿データのスキーマ
- `PostWithComments`: 投稿データにコメント情報を追加したスキーマ

## 10. 補足・制約
- ログイン状態でないと投稿一覧を表示できません。
- 投稿の取得に失敗した場合は、エラーメッセージを表示します。
- 投稿データが存在しない場合は、空の状態を表示します。
- 投稿の詳細ページへの遷移は、投稿の画像をクリックすることで行えます。
