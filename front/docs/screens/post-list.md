# 画面名
投稿一覧

# 必須構成

## 1. 画面概要
- 投稿された記事の一覧を表示する画面です。
- 投稿の詳細ページへのリンクが設置されています。
- 投稿に関するメタ情報(カテゴリ、コメント数、新着コメントの有無など)が表示されます。

## 2. URL
- `/posts`

## 3. フォーム項目・表示要素
- 投稿のサムネイル画像
- 投稿のタイトル
- 投稿者名
- 投稿日時
- 投稿のカテゴリ
- コメント数
- 新着コメントの有無

## 4. 初期表示・デフォルト値
- 投稿一覧は、投稿日時の降順で表示されます。
- 初期表示時は、投稿データの取得中を示すローディング状態が表示されます。

## 5. ユーザー操作
- 投稿のサムネイル画像をクリックすると、その投稿の詳細ページに遷移します。

## 6. バリデーション・エラーハンドリング
- 投稿データの取得に失敗した場合は、エラーメッセージが表示されます。
- 投稿データが存在しない場合は、空の状態を示すメッセージが表示されます。

## 7. 画面遷移
- 投稿のサムネイル画像をクリックすると、その投稿の詳細ページ(`/posts/:id`)に遷移します。
- ログインしていない場合は、ログインページ(`/login`)に遷移します。

## 8. 使用している コンポーネント
- `PostList`: 投稿一覧を表示するメインのコンポーネントです。
- `PhotoList`: 投稿のサムネイル画像を表示するコンポーネントです。
- `TagList`: 投稿のカテゴリを表示するコンポーネントです。
- `StatusInfo`: 投稿データの取得状態(ロード中、エラー、空)を表示するコンポーネントです。
- `Image`: 投稿者のアイコン画像を表示するコンポーネントです。

## 9. 使用している Hooks / Stores
- `usePostStore`: 投稿データの管理に使用しているストアです。
- `useRequireAuth`: ログイン状態の確認に使用しているカスタムフックです。

## 10. 補足・制約
- 投稿の詳細情報(コメントなど)は、別のページで表示されます。
- ログインしていない場合は、ログインページに遷移します。
