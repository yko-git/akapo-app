# 画面名
投稿一覧

# 必須構成

## 1. 画面概要
ユーザーが投稿した記事の一覧を表示する画面です。投稿にはカテゴリーやコメント数などの情報が含まれており、ユーザーはカテゴリーやユーザー名でフィルタリングできます。

## 2. URL
- `/posts`

## 3. フォーム項目・表示要素
- 投稿一覧
  - 投稿の画像
  - 投稿のタイトル
  - 投稿のカテゴリー
  - 投稿のコメント数
  - 投稿者の名前と画像
  - 投稿日時
- フィルターナビゲーション
  - カテゴリーフィルター
  - ユーザーフィルター

## 4. 初期表示・デフォルト値
- 投稿一覧は日付の降順で表示される
- カテゴリーフィルターとユーザーフィルターは初期状態では適用されない

## 5. ユーザー操作
- 投稿をクリックすると、投稿の詳細ページに遷移する
- カテゴリーフィルターを選択すると、選択したカテゴリーの投稿のみが表示される
- ユーザーフィルターを選択すると、選択したユーザーの投稿のみが表示される
- 「BACK」ボタンをクリックすると、トップページに遷移する

## 6. バリデーション・エラーハンドリング
- 投稿の取得に失敗した場合は、エラーメッセージを表示する
- 投稿データがない場合は、空の状態を表示する

## 7. 画面遷移
- 投稿の詳細ページ (`/posts/:id`)
- ログイン画面 (`/login`)

## 8. 使用しているコンポーネント
- `PostListPage`
- `FilterNav`
- `PostList`
- `StatusInfo`
- `PhotoList`
- `TagList`
- `Image`
- `Link`

## 9. 使用しているHooks / Stores / API / Schema
- Hooks
  - `useRequireAuth`
  - `useCategoryFilter`
  - `usePostsFilter`
- Stores
  - `usePostStore`
- API
  - `fetchPosts`
  - `fetchComments`
- Schema
  - `Post`
  - `PostWithComments`

## 10. 補足・制約
- 認証済みのユーザーのみがこの画面にアクセスできる
- 投稿の取得には時間がかかる可能性があるため、ローディング状態を表示する
- 新しいコメントがついた投稿には「NEW COMMENT」のラベルが表示される
