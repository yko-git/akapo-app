# 画面名
投稿一覧

# 必須構成

## 1. 画面概要
- ユーザーが投稿した記事の一覧を表示する画面です。
- 投稿の詳細情報や、新着コメントの表示、ページネーション機能などが含まれています。

## 2. URL
- `/posts`

## 3. フォーム項目・表示要素
- 投稿一覧
  - 投稿の画像
  - 投稿のタイトル
  - 投稿者名
  - 投稿日時
  - カテゴリータグ
  - コメント数
  - 新着コメントフラグ
- フィルターナビゲーション
  - カテゴリーフィルター
  - ユーザーフィルター
- ページネーション

## 4. 初期表示・デフォルト値
- 投稿一覧は最新の投稿から順に表示される
- カテゴリーフィルターとユーザーフィルターは初期状態では適用されない

## 5. ユーザー操作
- 投稿の画像をクリックすると、投稿の詳細ページに遷移する
- カテゴリーフィルターを選択すると、選択したカテゴリーの投稿のみ表示される
- ユーザーフィルターを選択すると、選択したユーザーの投稿のみ表示される
- ページネーションのボタンをクリックすると、次のページの投稿一覧が表示される

## 6. バリデーション・エラーハンドリング
- 投稿の取得に失敗した場合は、エラーメッセージを表示する
- 投稿データが存在しない場合は、空の状態を表示する

## 7. 画面遷移
- 投稿の詳細ページ(`/posts/:id`)に遷移できる
- ログイン画面(`/login`)に遷移できる

## 8. 使用しているコンポーネント
- `PostListPage`: 投稿一覧ページのメインコンポーネント
- `FilterNav`: カテゴリーとユーザーのフィルターナビゲーション
- `PostList`: 投稿一覧を表示するコンポーネント
- `StatusInfo`: 読み込み中、エラー、空の状態を表示するコンポーネント
- `PageNation`: ページネーションを表示するコンポーネント
- `PhotoList`: 投稿の画像を表示するコンポーネント
- `TagList`: 投稿のカテゴリータグを表示するコンポーネント

## 9. 使用しているHooks / Stores / API / Schema
- Hooks
  - `useRequireAuth`: ユーザーの認証状態を確認するフック
  - `useCategoryFilter`: URLクエリからカテゴリーフィルターの状態を取得するフック
  - `usePostsFilter`: ユーザーフィルターの状態を管理するフック
  - `usePostsPage`: ページネーションの状態を管理するフック
- Stores
  - `usePostStore`: 投稿データの状態を管理するストア
- API
  - `fetchPosts`: 投稿データを取得するAPI
  - `fetchComments`: 投稿のコメントデータを取得するAPI
- Schema
  - `Post`: 投稿データのスキーマ
  - `PostWithComments`: 投稿データにコメント情報を追加したスキーマ

## 10. 補足・制約
- ログインしていないユーザーはこの画面にアクセスできない
- 投稿の取得に失敗した場合は、エラーメッセージを表示する
- 投稿データが存在しない場合は、空の状態を表示する
- カテゴリーフィルターとユーザーフィルターは同時に適用できない
