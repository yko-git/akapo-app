# 画面名
新規ユーザー作成

# 必須構成

## 1. 画面概要
新規ユーザー登録を行うための画面です。ログインID、パスワード、アカウント名、アイコン画像の入力フォームが表示されます。

## 2. URL
`/register`

## 3. フォーム項目・表示要素
- ログインID (テキスト入力)
- パスワード (パスワード入力)
- アカウント名 (テキスト入力)
- アイコン画像 (ファイル選択)
- 登録ボタン

## 4. 初期表示・デフォルト値
- ログインID、パスワード、アカウント名の各入力フィールドは空の状態で表示されます。
- アイコン画像は選択されていない状態で表示されます。

## 5. ユーザー操作
- ログインID、パスワード、アカウント名を入力します。
- アイコン画像をファイル選択します。
- 登録ボタンをクリックすると、入力情報が送信されます。

## 6. バリデーション・エラーハンドリング
- ログインID、パスワード、アカウント名の各入力項目は必須入力です。
- パスワードは一定の複雑性が要求されます。
- アイコン画像のファイルサイズが大きい場合は、圧縮処理を行います。
- 入力エラーがある場合は、エラーメッセージを表示します。
- 登録処理中は、ボタンをdisabledにして二重送信を防ぎます。
- 登録に失敗した場合は、エラーメッセージを表示します。

## 7. 画面遷移
- 登録完了後は、ログイン画面(`/login`)に遷移します。

## 8. 使用しているコンポーネント
- `CreateUser`: 新規ユーザー登録フォームを表示するコンポーネント
- `Button`: 登録ボタンを表示するコンポーネント

## 9. 使用しているHooks / Stores
- `useUserForm`: ユーザー登録フォームの状態管理と入力値バリデーションを行うカスタムフック
- `useRouter`: ページ遷移を行うためのフック

## 10. 補足・制約
- 画像ファイルの圧縮処理を行うため、登録完了までに時間がかかる可能性があります。
- 登録可能な時間帯は午前9時から午後9時までとなっています。
