# 画面名
新規ユーザー作成

# 必須構成

## 1. 画面概要
新規ユーザーの登録を行う画面です。ログインID、パスワード、アカウント名、アイコン画像の入力を行い、新規ユーザーを作成することができます。

## 2. URL
`/register`

## 3. フォーム項目・表示要素
- ログインID
- パスワード
- アカウント名
- アイコン画像

## 4. 初期表示・デフォルト値
- ログインID、パスワード、アカウント名の各入力フィールドは空の状態で表示されます。
- アイコン画像の入力フィールドは空の状態で表示されます。

## 5. ユーザー操作
- ログインID、パスワード、アカウント名を入力します。
- アイコン画像をアップロードします。
- 「登録する」ボタンをクリックすると、新規ユーザーの登録が行われます。

## 6. バリデーション・エラーハンドリング
- ログインID、パスワード、アカウント名の各入力フィールドは必須項目です。
- パスワードは一定の複雑性を持つ必要があります。
- アイコン画像のファイルサイズが大きい場合は、圧縮処理を行います。
- 入力内容に問題がある場合は、エラーメッセージを表示します。
- 新規ユーザー登録に失敗した場合は、エラーメッセージを表示します。

## 7. 画面遷移
- 新規ユーザー登録が完了すると、ログイン画面(`/login`)に遷移します。

## 8. 使用しているコンポーネント
- `CreateUser`: 新規ユーザー登録のフォームを表示するコンポーネント
- `Button`: ボタンコンポーネント

## 9. 使用しているHooks / Stores
- `useUserForm`: ユーザーフォームの状態管理と入力値のバリデーションを行うカスタムフック
- `useRouter`: Next.jsのルーティングを管理するフック

## 10. 補足・制約
- 新規ユーザー登録は、午前9時から午後9時の間のみ可能です。
- アイコン画像のファイルサイズが大きい場合、登録完了までに時間がかかることがあります。
