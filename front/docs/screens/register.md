# 画面名
新規ユーザー作成

# 必須構成

## 1. 画面概要
新規ユーザー登録を行うための画面です。ログインID、パスワード、アカウント名、アイコン画像の入力フォームが表示されます。

## 2. URL
`/register`

## 3. フォーム項目・表示要素
- ログインID
- パスワード
- アカウント名
- アイコン画像

## 4. 初期表示・デフォルト値
- ログインID、パスワード、アカウント名の各入力フィールドは空の状態で表示されます。
- アイコン画像は初期表示では表示されません。

## 5. ユーザー操作
- ログインID、パスワード、アカウント名を入力します。
- アイコン画像をアップロードします。
- 「登録する」ボタンをクリックすると、入力内容が送信されます。

## 6. バリデーション・エラーハンドリング
- ログインID、パスワード、アカウント名の各入力フィールドは必須項目です。
- パスワードは一定の複雑性を持つ必要があります。
- アイコン画像のファイル形式は画像形式（jpg、png、gif など）である必要があります。
- 入力内容に問題がある場合は、エラーメッセージが表示されます。
- 登録処理中は「登録中...」と表示され、ボタンが無効化されます。
- 登録に成功した場合は、成功メッセージが表示され、ログイン画面に遷移します。
- 登録に失敗した場合は、エラーメッセージが表示されます。

## 7. 画面遷移
- 「登録する」ボタンをクリックすると、ログイン画面に遷移します。

## 8. 使用しているコンポーネント
- `CreateUser`: 新規ユーザー登録フォームを表示するコンポーネント
- `Button`: ボタンコンポーネント

## 9. 使用しているHooks / Stores
- `useUserForm`: ユーザーフォームの状態管理と入力値のバリデーションを行うカスタムフック
- `useRouter`: Next.js の useRouter フック

## 10. 補足・制約
- 画像サイズが大きい場合、登録完了まで時間がかかることがあるため、ユーザーに待機を促す注意書きが表示されます。
- 登録可能な時間帯は午前9時から午後9時までです。
