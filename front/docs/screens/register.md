# 画面名
新規ユーザー作成

# 必須構成

## 1. 画面概要
新規ユーザー登録を行うための画面です。ユーザーは自身のログインID、パスワード、アカウント名、アイコン画像を入力し、登録を行うことができます。

## 2. URL
`/register`

## 3. フォーム項目・表示要素
- ログインID
- パスワード
- アカウント名
- アイコン画像

## 4. 初期表示・デフォルト値
- ログインID、パスワード、アカウント名の各フォーム項目は空の状態で表示されます。
- アイコン画像は初期表示では表示されません。

## 5. ユーザー操作
- ユーザーはログインID、パスワード、アカウント名を入力します。
- ユーザーはアイコン画像をアップロードすることができます。
- ユーザーは「登録する」ボタンをクリックすることで、新規ユーザー登録を行うことができます。

## 6. バリデーション・エラーハンドリング
- ログインID、パスワード、アカウント名の各フォーム項目は必須入力項目です。
- パスワードは一定の複雑性を持つ必要があります。
- アイコン画像のファイルサイズが大きい場合は、圧縮処理を行います。
- 登録に失敗した場合はエラーメッセージを表示します。

## 7. 画面遷移
- 新規ユーザー登録が完了すると、ログイン画面(`/login`)に遷移します。

## 8. 使用しているコンポーネント
- `CreateUser`: 新規ユーザー登録フォームを表示するコンポーネント
- `Button`: ボタンコンポーネント

## 9. 使用しているHooks / Stores / API / Schema
- `useUserForm`: ユーザーフォームの状態管理と入力値のバリデーションを行うカスタムフック
- `createUser`: 新規ユーザー登録APIを呼び出す関数
- `NewUserSchema`: ユーザー登録時の入力値スキーマ

## 10. 補足・制約
- 画像サイズが大きい場合、登録完了まで時間がかかることがあるため、ユーザーに待機を促すメッセージを表示しています。
- 新規ユーザー登録は午前9時から午後9時の間のみ可能です。
