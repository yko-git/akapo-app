# 画面名
新規ユーザー作成

# 必須構成

## 1. 画面概要
新規ユーザーの登録を行う画面です。ログインID、パスワード、アカウント名、アイコン画像の入力フォームが表示されます。

## 2. URL
`/register`

## 3. フォーム項目・表示要素
- ログインID (テキスト入力)
- パスワード (パスワード入力)
- アカウント名 (テキスト入力)
- アイコン画像 (ファイル選択)
- 登録ボタン

## 4. 初期表示・デフォルト値
- ログインID、パスワード、アカウント名の各入力フィールドは空の状態で表示されます。
- アイコン画像は初期表示では表示されません。

## 5. ユーザー操作
- ログインID、パスワード、アカウント名を入力する
- アイコン画像をファイル選択する
- 登録ボタンをクリックする

## 6. バリデーション・エラーハンドリング
- ログインID、パスワード、アカウント名の各入力フィールドは必須入力です。
- パスワードは一定の複雑性を持つ必要があります。
- アイコン画像のファイルサイズが大きい場合は、圧縮処理を行います。
- 入力内容に問題がある場合はエラーメッセージを表示します。
- 登録処理中はローディング表示を行います。
- 登録に失敗した場合はエラーメッセージを表示します。

## 7. 画面遷移
- 登録完了後は、ログイン画面(`/login`)に遷移します。

## 8. 使用しているコンポーネント
- `CreateUser`: 新規ユーザー登録フォームを表示するコンポーネント
- `Button`: ボタンコンポーネント

## 9. 使用しているHooks / Stores / API / Schema
- `useUserForm`: ユーザー登録フォームの状態管理と入力値バリデーションを行うカスタムフック
- `createUser`: ユーザー登録APIを呼び出す関数
- `NewUserSchema`: ユーザー登録フォームの入力値スキーマ

## 10. 補足・制約
- アイコン画像のファイルサイズが大きい場合は、登録完了までに時間がかかることがあります。
- 登録は午前9時から午後9時の間のみ可能です。
