```markdown
# 画面名
ログイン

## 画面概要
本画面はユーザーがログインするための画面です。ユーザーはログインIDとパスワードを入力してログインを行うことができます。
ログイン成功時は、ユーザーのプロフィール情報をグローバルストアに保存し、マイページへ遷移します。

## URL
/login

## フォーム項目・表示要素
1. ログインID (必須)
2. パスワード (必須)
3. ログインボタン

## 初期表示・デフォルト値
- フォーム項目はすべて空の状態で表示されます。

## ユーザー操作
1. ユーザーはログインIDとパスワードを入力し、ログインボタンをクリックする。
2. ログイン処理が完了したら、ユーザープロフィール情報をグローバルストアに保存し、マイページ(/mypage)に遷移する。

## バリデーション・エラーハンドリング
1. ログインID、パスワードは必須入力項目です。未入力の場合はエラーメッセージを表示します。
2. ログイン処理が失敗した場合は、エラーメッセージ「ログインに失敗しました」をトーストで表示します。

## 画面遷移
- 「まだアカウントをお持ちでない方はこちら」のリンクをクリックすると、新規ユーザー登録ページ(/signup)に遷移します。

## 使用しているコンポーネント
1. Button
2. Input

## 使用している Hooks / Stores
1. useLoginForm
2. useAuthStore

## 補足・制約
- ログインは午前9時から午後9時の間のみ可能です。

```
