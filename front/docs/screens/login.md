# 画面仕様書

## 画面概要
ログイン画面です。ユーザーはログインIDとパスワードを入力し、ログインすることができます。ログイン成功時は、ユーザー情報を取得してMyPageへ遷移します。

## URL
/login

## 使用コンポーネント
- LoginUser
- Button
- Input

## フォーム項目・表示要素
- ログインID
- パスワード
- ログインボタン

## 初期表示・デフォルト値
- フォーム項目は空欄の状態で初期表示されます。
- デフォルト値はありません。

## ユーザー操作
1. ログインIDとパスワードを入力する
2. ログインボタンをクリックする

## API連携
1. ログイン処理は `createLogin` APIを呼び出して行います。
2. ログイン成功後は `fetchUserData` APIを呼び出し、ユーザー情報を取得しています。

## バリデーション・エラーハンドリング
- ログインIDとパスワードは必須入力項目です。
- バリデーションエラーが発生した場合は、エラーメッセージを表示します。
- ログイン処理でエラーが発生した場合は、エラーメッセージをToastで表示します。

## 補足・制約
- ログイン・新規ユーザー登録は午前9時〜午後9時の間のみ利用可能です。
