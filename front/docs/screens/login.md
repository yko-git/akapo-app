# 画面仕様書

## 画面概要
このページはログイン機能を提供しており、ユーザーが自身のアカウントでログインできます。

## URL
- `/login`

## 使用コンポーネント
- `LoginUser`: ログインフォームを提供するメインコンポーネント
- `Button`: 共通のボタンコンポーネント
- `font`: 共通のフォントスタイルを定義するコンポーネント

## フォーム項目・表示要素
- ログインID
- パスワード
- ログインボタン

## 初期表示・デフォルト値
- 初期表示時は、ログインフォームが表示されます。
- 入力項目には初期値はありません。

## ユーザー操作
1. ユーザーはログインIDとパスワードを入力します。
2. ユーザーはログインボタンをクリックすることで、ログイン処理が開始されます。

## API連携
1. `createLogin()` API: ログイン処理を行う API を呼び出します。
2. `fetchUserData()` API: ログイン後、ユーザーデータを取得します。

## バリデーション・エラーハンドリング
- ログインIDとパスワードの入力は必須です。
- 入力チェックはカスタムフックの `useLoginForm` で行われています。
- 入力エラーがある場合、エラーメッセージが表示されます。
- ログイン処理中は「ログイン中...」と表示され、ボタンは無効化されます。
- ログイン失敗時は、エラーメッセージが表示されます。

## 補足・制約
- ログイン・新規ユーザー登録は午前9時〜午後9時の間にのみ利用可能です。
