# 画面仕様書

## 画面概要
ログイン画面です。ユーザーがログインIDとパスワードを入力し、ログインすることができます。ログイン成功時は、ユーザー情報をストアに保存し、マイページにリダイレクトされます。

## URL
/login

## 使用コンポーネント
- `LoginUser`: ログインフォームを表示するメインコンポーネント
- `Button`: ログインボタンのコンポーネント
- `useLoginForm`: ログインフォームのバリデーションロジックを提供するカスタムフック

## フォーム項目・表示要素
- ログインID: ユーザーがログインIDを入力するテキストフィールド
- パスワード: ユーザーがパスワードを入力するテキストフィールド
- ログインボタン: ユーザーがクリックしてログインを実行する

## 初期表示・デフォルト値
- 特になし

## ユーザー操作
1. ユーザーがログインIDとパスワードを入力する
2. ユーザーがログインボタンをクリックする
3. ログイン処理が完了すると、ユーザー情報がストアに保存され、マイページにリダイレクトされる

## API連携
- `createLogin`: ログイン処理を行う API を呼び出す
- `fetchUserData`: ログイン成功後にユーザー情報を取得する API を呼び出す

## バリデーション・エラーハンドリング
- `useLoginForm` カスタムフックを使用してログインフォームのバリデーションを行っている
- ログイン処理に失敗した場合は、エラーメッセージをToastで表示する

## 補足・制約
- コード上では、ログインIDとパスワードの長さやフォーマットなどの具体的なバリデーション条件は不明です。
- ログイン可能時間については、コード上では不明ですが、画面上部に「午前9時〜午後9時の間にご利用いただけます」と表示されています。
