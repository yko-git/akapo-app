# 画面名
ログイン

# 画面仕様

## 1. 画面概要
ユーザーがログインできる画面です。ログインIDとパスワードを入力し、ログインボタンをクリックすることで、ログインが完了します。

## 2. URL
`/login`

## 3. フォーム項目・表示要素
- ログインID (テキスト入力)
- パスワード (パスワード入力)
- ログインボタン

## 4. 初期表示・デフォルト値
- 特になし

## 5. ユーザー操作
1. ログインIDとパスワードを入力する
2. ログインボタンをクリックする

## 6. バリデーション・エラーハンドリング
- ログインIDとパスワードが未入力の場合、エラーメッセージを表示する
- ログイン処理に失敗した場合、エラーメッセージを表示する

## 7. 画面遷移
- ログイン成功時は `/mypage` に遷移する
- 新規アカウント登録ボタンをクリックすると `/signup` に遷移する

## 8. 使用しているコンポーネント
- `Button`: ログインボタンを表示するコンポーネント
- `LoginUser`: ログインフォームを表示するコンポーネント

## 9. 使用しているHooks / Stores
- `useLoginForm`: ログインフォームの状態管理と入力値のバリデーションを行うカスタムフック
- `useAuthStore`: ユーザープロファイル情報の管理を行うストア

## 10. 補足・制約
- ログイン処理は午前9時から午後9時の間のみ利用可能
- ログイン成功時にはユーザープロファイル情報を取得し、ストアに保存する
