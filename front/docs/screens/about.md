# 画面名
About

# 必須構成

## 1. 画面概要
このページは、子どもたちの作品を気軽に投稿・共有できるサイトの「About」ページです。サイトの概要や新規ユーザー登録のボタンが表示されています。

## 2. URL
`/about`

## 3. フォーム項目・表示要素
- サイトのロゴ
- 「ABOUT」のタイトル
- 作品の紹介文
- 新規ユーザー登録ボタン

## 4. 初期表示・デフォルト値
- 特になし

## 5. ユーザー操作
- 新規ユーザー登録ボタンをクリックすると、サインアップページ(`/signup`)に遷移する

## 6. バリデーション・エラーハンドリング
- 特になし

## 7. 画面遷移
- 新規ユーザー登録ボタンをクリックすると、サインアップページ(`/signup`)に遷移する

- `Image`: Next.jsの画像表示コンポーネント
- `Link`: Next.jsのリンクコンポーネント
- `Button`: 共通のボタンコンポーネント
- `jost`: 共通のフォントコンポーネント
