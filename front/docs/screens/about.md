# 画面名
About

# 画面仕様

## 1. 画面概要
このページは、このサイトの概要を説明するための画面です。サイトの目的や特徴、新規ユーザー登録へのリンクが表示されます。

## 2. URL
`/about`

## 3. フォーム項目・表示要素
- サイトのロゴ画像
- 「ABOUT」のタイトル
- サイトの説明文
- 新規ユーザー登録ボタン

## 4. 初期表示・デフォルト値
- 画面全体が表示されます。
- 特に初期表示やデフォルト値はありません。

## 5. ユーザー操作
- 新規ユーザー登録ボタンをクリックすると、新規ユーザー登録ページ(`/signup`)に遷移します。

## 6. バリデーション・エラーハンドリング
- 特にバリデーションやエラーハンドリングはありません。

## 7. 画面遷移
- 新規ユーザー登録ボタンをクリックすると、新規ユーザー登録ページ(`/signup`)に遷移します。

- `Image`: Next.jsの画像表示コンポーネント
- `Link`: Next.jsのリンクコンポーネント
- `Button`: 共通のボタンコンポーネント
