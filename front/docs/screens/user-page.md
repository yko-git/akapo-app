# 画面名
ユーザー投稿一覧

# 必須構成

## 1. 画面概要
ユーザーの投稿一覧を表示する画面です。ユーザーのプロフィール情報と、ユーザーが投稿した記事の一覧が表示されます。また、新しい投稿を作成するためのボタンも用意されています。

## 2. URL
/mypage

## 3. フォーム項目・表示要素
- ユーザーのプロフィール情報
  - ユーザーアイコン
  - ユーザー名
- ユーザーの投稿一覧
  - 投稿一覧ページ

## 4. 初期表示・デフォルト値
- ユーザーのプロフィール情報は、ログイン中のユーザーの情報が表示されます。
- ユーザーの投稿一覧は、ログイン中のユーザーが投稿した記事が表示されます。

## 5. ユーザー操作
- ログアウトボタンをクリックすると、ログアウトしてログイン画面に遷移します。
- 「新しい投稿を作成」ボタンをクリックすると、新規投稿ページに遷移します。

## 6. バリデーション・エラーハンドリング
- ユーザー情報の取得やユーザーの投稿一覧の取得に失敗した場合は、エラーメッセージが表示されます。

## 7. 画面遷移
- ログアウトボタンをクリックすると、ログイン画面(/login)に遷移します。
- 「新しい投稿を作成」ボタンをクリックすると、新規投稿ページ(/posts/new)に遷移します。

## 8. 使用しているコンポーネント
- User
- Button
- StatusInfo
- Image
- UserPostListPage

## 9. 使用しているHooks / Stores
- useAuthStore
- usePostStore
- useRequireAuth
- useRouter
- useEffect

## 10. 補足・制約
- ログイン状態でのみアクセスできる画面です。
- ユーザー情報とユーザーの投稿一覧は、API経由で取得しています。
