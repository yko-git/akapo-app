# 画面名
ユーザー投稿一覧

# 必須構成

## 1. 画面概要
ユーザーの投稿一覧を表示する画面です。ユーザーのプロフィール情報と、ユーザーが投稿した記事の一覧が表示されます。また、新しい投稿を作成するためのボタンも用意されています。

## 2. URL
/mypage

## 3. フォーム項目・表示要素
- ユーザーのプロフィール情報
  - ユーザーアイコン
  - ユーザー名
- ユーザーの投稿一覧
- 新しい投稿を作成するためのボタン
- ログアウトボタン

## 4. 初期表示・デフォルト値
- ユーザーのプロフィール情報は、ログイン時に取得したデータが表示されます。
- ユーザーの投稿一覧は、ログイン時に取得したデータが表示されます。

## 5. ユーザー操作
- ユーザーは新しい投稿を作成するためのボタンをクリックできます。
- ユーザーはログアウトボタンをクリックしてログアウトできます。

## 6. バリデーション・エラーハンドリング
- ユーザープロフィールの取得やユーザー投稿の取得に失敗した場合、エラーメッセージが表示されます。

## 7. 画面遷移
- 新しい投稿を作成するためのボタンをクリックすると、投稿作成ページ(/posts/new)に遷移します。
- ログアウトボタンをクリックすると、ログインページ(/login)に遷移します。

## 8. 使用している コンポーネント
- User
- Button
- StatusInfo
- Image
- UserPostListPage

## 9. 使用している Hooks / Stores / API / Schema
- useAuthStore
- usePostStore
- useRequireAuth
- fetchUserData
- fetchUserPosts

## 10. 補足・制約
- ユーザープロフィールの取得やユーザー投稿の取得は、ログイン状態が確認された後に行われます。
- ログアウト機能は、ログアウトボタンをクリックすることで実現されます。
