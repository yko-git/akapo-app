# 画面名
ユーザー投稿一覧

# 必須構成

## 1. 画面概要
ユーザーの投稿一覧を表示する画面です。ユーザーのプロフィール情報と、ユーザーが投稿した記事の一覧が表示されます。また、新しい投稿を作成するためのボタンも用意されています。

## 2. URL
- `/mypage`

## 3. フォーム項目・表示要素
- ユーザーのプロフィール情報
  - ユーザーアイコン
  - ユーザー名
- ユーザーの投稿一覧
  - 投稿一覧ページ

## 4. 初期表示・デフォルト値
- ユーザーのプロフィール情報が表示されます。
- ユーザーの投稿一覧が表示されます。

## 5. ユーザー操作
- ログアウトボタンをクリックすると、ログアウトしてログイン画面に遷移します。
- 「新しい投稿を作成」ボタンをクリックすると、新規投稿ページに遷移します。

## 6. バリデーション・エラーハンドリング
- ユーザー情報の取得に失敗した場合、エラーメッセージが表示されます。

## 7. 画面遷移
- ログアウトボタンをクリックすると、ログイン画面(`/login`)に遷移します。
- 「新しい投稿を作成」ボタンをクリックすると、新規投稿ページ(`/posts/new`)に遷移します。

## 8. 使用している コンポーネント
- `User`: ユーザーのプロフィール情報を表示するコンポーネント
- `UserPostListPage`: ユーザーの投稿一覧を表示するコンポーネント
- `Button`: ボタンコンポーネント
- `StatusInfo`: ローディング状態やエラー状態を表示するコンポーネント
- `Image`: 画像表示コンポーネント

## 9. 使用している Hooks / Stores / API / Schema
- `useAuthStore`: ユーザー認証に関するストア
- `usePostStore`: 投稿に関するストア
- `useRequireAuth`: 認証状態を確認するカスタムフック
- `fetchUserData`: ユーザー情報を取得するAPI
- `fetchUserPosts`: ユーザーの投稿一覧を取得するAPI
- `UserProfile`: ユーザープロフィールのスキーマ
- `Post`: 投稿のスキーマ

## 10. 補足・制約
- ユーザーがログインしていない場合、ログイン画面に遷移します。
- ユーザー情報の取得に失敗した場合、エラーメッセージが表示されます。
