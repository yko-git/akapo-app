# 画面名
ユーザー投稿一覧

# 必須構成

## 1. 画面概要
ユーザーの投稿一覧を表示する画面です。ユーザーのプロフィール情報と、ユーザーが投稿した記事の一覧が表示されます。また、新しい投稿を作成するためのボタンも用意されています。

## 2. URL
/mypage

## 3. フォーム項目・表示要素
- ユーザーのプロフィール情報
  - ユーザーアイコン
  - ユーザー名
- ユーザーの投稿一覧
  - 投稿一覧ページ
- 新しい投稿を作成するためのボタン
- ログアウトボタン

## 4. 初期表示・デフォルト値
- ユーザーのプロフィール情報は、ログイン中のユーザーの情報が表示されます。
- ユーザーの投稿一覧は、ログイン中のユーザーが投稿した記事が表示されます。

## 5. ユーザー操作
- ユーザーアイコンをクリックすると、ユーザープロフィールページに遷移します。
- 新しい投稿を作成するボタンをクリックすると、新規投稿ページに遷移します。
- ログアウトボタンをクリックすると、ログアウトが実行され、ログイン画面に遷移します。

## 6. バリデーション・エラーハンドリング
- ユーザー情報の取得に失敗した場合は、エラーメッセージを表示します。
- 投稿の取得に失敗した場合は、エラーメッセージを表示します。

## 7. 画面遷移
- ユーザープロフィールページ: /mypage
- 新規投稿ページ: /posts/new
- ログイン画面: /login

## 8. 使用しているコンポーネント
- User
- Button
- StatusInfo
- Image
- UserPostListPage

## 9. 使用しているHooks / Stores / API / Schema
- useAuthStore
- usePostStore
- useRequireAuth
- fetchUserData
- fetchUserPosts

## 10. 補足・制約
- ログイン中のユーザーのみがこの画面にアクセスできます。
- ユーザー情報と投稿データは非同期で取得されます。
