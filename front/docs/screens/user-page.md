# 画面名
ユーザー投稿一覧

# 必須構成

## 1. 画面概要
ユーザーの投稿一覧を表示する画面です。ユーザーのプロフィール情報と、ユーザーが投稿した記事の一覧が表示されます。また、新しい投稿を作成するためのボタンも用意されています。

## 2. URL
/mypage

## 3. フォーム項目・表示要素
- ユーザーのプロフィール情報
  - ユーザーアイコン
  - ユーザー名
- ユーザーの投稿一覧
- 新しい投稿を作成するためのボタン
- ログアウトボタン

## 4. 初期表示・デフォルト値
- ユーザーのプロフィール情報は、ログイン時に取得したデータが表示されます。
- ユーザーの投稿一覧は、ログイン時に取得したデータが表示されます。

## 5. ユーザー操作
- ユーザーは新しい投稿を作成するためのボタンをクリックできます。
- ユーザーはログアウトボタンをクリックしてログアウトできます。

## 6. バリデーション・エラーハンドリング
- ユーザーのプロフィール情報や投稿の取得に失敗した場合は、エラーメッセージが表示されます。
- ローディング中は、ローディング状態を示すコンポーネントが表示されます。

## 7. 画面遷移
- 新しい投稿を作成するためのボタンをクリックすると、投稿作成ページ(/posts/new)に遷移します。
- ログアウトボタンをクリックすると、ログイン画面(/login)に遷移します。

## 8. 使用している コンポーネント
- User
- Button
- StatusInfo
- Image
- UserPostListPage

## 9. 使用している Hooks / Stores / API / Schema
- useAuthStore
- usePostStore
- useRequireAuth
- fetchUserData
- fetchUserPosts
- UserProfile
- Post

## 10. 補足・制約
- ユーザーがログインしていない場合は、ログイン画面に遷移します。
- ユーザーのプロフィール情報や投稿の取得に失敗した場合は、エラーメッセージが表示されます。
