# 画面名
ユーザー投稿一覧

# 必須構成

## 1. 画面概要
ユーザーの投稿一覧を表示する画面です。ユーザーのプロフィール情報と、ユーザーが投稿した記事の一覧が表示されます。また、新しい投稿を作成するためのボタンも用意されています。

## 2. URL
`/mypage`

## 3. フォーム項目・表示要素
- ユーザーのプロフィール情報
  - ユーザーアイコン
  - ユーザー名
- ユーザーの投稿一覧
- 新しい投稿を作成するためのボタン
- ログアウトボタン

## 4. 初期表示・デフォルト値
- ユーザーのプロフィール情報は、ログイン中のユーザーの情報が表示されます。
- ユーザーの投稿一覧は、ログイン中のユーザーが投稿した記事が表示されます。

## 5. ユーザー操作
- ユーザーは新しい投稿を作成するためのボタンをクリックできます。
- ユーザーはログアウトボタンをクリックしてログアウトできます。

## 6. バリデーション・エラーハンドリング
- ユーザーのプロフィール情報や投稿の取得に失敗した場合は、エラーメッセージが表示されます。
- 投稿の取得中は、ローディング表示が行われます。

## 7. 画面遷移
- 新しい投稿を作成するためのボタンをクリックすると、投稿作成ページ(`/posts/new`)に遷移します。
- ログアウトボタンをクリックすると、ログイン画面(`/login`)に遷移します。

## 8. 使用している コンポーネント
- `User`: ユーザーのプロフィール情報を表示するコンポーネント
- `Button`: ボタンを表示するコンポーネント
- `StatusInfo`: ローディングやエラー表示を行うコンポーネント
- `Image`: 画像を表示するコンポーネント
- `UserPostListPage`: ユーザーの投稿一覧を表示するコンポーネント

## 9. 使用している Hooks / Stores
- `useAuthStore`: ユーザー認証に関する状態を管理するストア
- `usePostStore`: 投稿に関する状態を管理するストア
- `useRequireAuth`: ユーザー認証状態を確認するフック
- `useEffect`: コンポーネントのライフサイクルを管理するフック
- `useRouter`: ページ遷移に関する機能を提供するフック

## 10. 補足・制約
- ユーザーがログアウト状態の場合、ログイン画面に遷移されます。
- ユーザーのプロフィール情報や投稿の取得に失敗した場合、エラーメッセージが表示されます。
