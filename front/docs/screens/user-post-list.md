# 画面名
ユーザー投稿一覧

# 必須構成

## 1. 画面概要
ユーザーが投稿した記事の一覧を表示する画面です。記事のタイトル、本文、画像、カテゴリーが表示され、編集と削除の操作ができます。

## 2. URL
`/user-post-list`

## 3. フォーム項目・表示要素
- 記事のタイトル
- 記事の本文
- 記事の画像
- 記事のカテゴリー
- 編集ボタン
- 削除ボタン

## 4. 初期表示・デフォルト値
- ユーザーが投稿した記事の一覧が表示されます。
- 記事は投稿日時の降順で表示されます。
- 記事がない場合は「投稿がありません。」と表示されます。

## 5. ユーザー操作
- 記事のタイトルをクリックすると、その記事の詳細ページに遷移します。
- 編集ボタンをクリックすると、記事の編集ページに遷移します。
- 削除ボタンをクリックすると、記事の削除確認ダイアログが表示され、削除を実行できます。

## 6. バリデーション・エラーハンドリング
- 記事の削除時に、サーバーとの通信エラーが発生した場合は、エラーメッセージを表示します。

## 7. 画面遷移
- 記事の詳細ページ (`/posts/:id`)
- 記事の編集ページ (`/posts/new/:id`)

## 8. 使用しているコンポーネント
- `UserPostList`: 記事一覧を表示するメインコンポーネント
- `Button`: 編集・削除ボタンのコンポーネント
- `Link`: 記事のタイトルリンクのコンポーネント
- `Image`: 記事の画像を表示するコンポーネント

## 9. 使用しているHooks / Stores
- `usePostStore`: 記事の状態管理に使用しているストア

## 10. 補足・制約
- 記事の削除は、サーバーとの通信を通して行われます。
- 記事の表示順は投稿日時の降順になっています。
