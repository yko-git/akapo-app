# 画面名
ユーザー投稿一覧

# 必須構成

## 1. 画面概要
ユーザーが投稿した記事の一覧を表示する画面です。記事のタイトル、本文、画像、カテゴリーを表示し、編集と削除の機能を提供します。

## 2. URL
`/mypage`

## 3. フォーム項目・表示要素
- 記事のタイトル
- 記事の本文
- 記事の画像
- 記事のカテゴリー
- 編集ボタン
- 削除ボタン

## 4. 初期表示・デフォルト値
- ユーザーが投稿した記事の一覧が表示されます。
- 記事は投稿日時の降順で表示されます。
- 投稿がない場合は「投稿がありません。」と表示されます。

## 5. ユーザー操作
- 記事のタイトルをクリックすると、その記事の詳細ページ(`/posts/:id`)に遷移します。
- 編集ボタンをクリックすると、記事の編集ページ(`/posts/new/:id`)に遷移します。
- 削除ボタンをクリックすると、記事の削除確認ダイアログが表示され、削除を確認できます。

## 6. バリデーション・エラーハンドリング
- 記事の削除時に、サーバーからエラーが返された場合は、エラーメッセージをトースト通知で表示します。

## 7. 画面遷移
- 記事のタイトルをクリックすると、記事の詳細ページ(`/posts/:id`)に遷移します。
- 編集ボタンをクリックすると、記事の編集ページ(`/posts/new/:id`)に遷移します。

## 8. 使用しているコンポーネント
- `UserPostList`: 記事一覧を表示するコンポーネント
- `Button`: ボタンコンポーネント
- `Link`: Next.js の Link コンポーネント
- `Image`: Next.js の Image コンポーネント

## 9. 使用しているHooks / Stores
- `usePostStore`: 記事の状態を管理するストア
- `deletePost`: 記事を削除するAPIコール

## 10. 補足・制約
- 記事の削除は、サーバーサイドで処理されます。
- 記事の一覧は、ストアから取得しています。
