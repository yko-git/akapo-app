# 画面名
投稿詳細

# 必須構成

## 1. 画面概要
投稿の詳細情報を表示する画面です。投稿の内容、投稿者情報、コメント一覧、新規コメント投稿フォームが含まれています。

## 2. URL
`/posts/:id`

## 3. フォーム項目・表示要素
- 投稿タイトル
- 投稿本文
- 投稿者アイコン
- 投稿者名
- 投稿日時
- カテゴリータグ一覧
- コメント一覧
- 新規コメント投稿フォーム

## 4. 初期表示・デフォルト値
- 投稿IDに対応する投稿データを取得し、画面に表示する
- 投稿データが取得できない場合は、エラー表示を行う
- 投稿データの取得中は、ローディング表示を行う

## 5. ユーザー操作
- 投稿一覧ページへのリンクをクリックすると、投稿一覧ページに遷移する
- コメント一覧の下部にある新規コメント投稿フォームから、コメントを投稿できる

## 6. バリデーション・エラーハンドリング
- 新規コメント投稿フォームのバリデーションは行わない
- 投稿データの取得に失敗した場合は、エラーメッセージを表示する

## 7. 画面遷移
- 投稿一覧ページ(`/`)へのリンクが存在する

## 8. 使用しているコンポーネント
- `Article`: 投稿の詳細情報を表示するメインコンポーネント
- `TagList`: 投稿のカテゴリータグ一覧を表示するコンポーネント
- `Photo`: 投稿の画像を表示するコンポーネント
- `CommentList`: 投稿に紐づくコメント一覧を表示するコンポーネント
- `CreateComment`: 新規コメント投稿フォームを表示するコンポーネント
- `StatusInfo`: 読み込み中やエラー時の状態を表示するコンポーネント

## 9. 使用しているHooks / Stores
- `useRequireAuth`: 認証状態を確認するカスタムフック
- `usePostStore`: 投稿データの管理に使用するストア
- `useCommentStore`: コメントデータの管理に使用するストア

## 10. 補足・制約
- 認証状態が確認できるまでは、投稿データの取得を行わない
- 投稿データの取得に失敗した場合は、エラーメッセージを表示する
- 投稿データが取得できない場合は、適切な状態表示を行う
