# 画面仕様書

## 画面概要
投稿の詳細画面です。投稿の内容、ユーザー情報、コメント一覧、新規コメント投稿フォームが表示されます。

## URL
`/posts/:id`

## 使用コンポーネント
- `Article`
- `TagList`
- `Photo`
- `CommentList`
- `CreateComment`
- `StatusInfo`

## フォーム項目・表示要素
- 投稿タイトル
- 投稿本文
- 投稿者名
- 投稿者アイコン
- 投稿日時
- 投稿カテゴリ一覧
- コメント一覧
- コメント投稿フォーム

## 初期表示・デフォルト値
- 初期表示時は、クエリパラメータの `id` に対応する投稿データが取得されます。
- 投稿データの取得中は `StatusInfo` コンポーネントが表示されます。
- 投稿データの取得に失敗した場合も `StatusInfo` コンポーネントが表示されます。

## ユーザー操作
- 「BACK」リンクをクリックすると、トップページ (`/`) に遷移します。
- コメント一覧の下部にある「コメントを書く」ボタンをクリックすると、コメント投稿フォームが表示されます。
- コメント投稿フォームにテキストを入力し、「送信」ボタンをクリックすると、新規コメントが投稿されます。

## API連携
- `fetchPost` API を使用して、クエリパラメータの `id` に対応する投稿データを取得します。
- `fetchComments` API を使用して、投稿に紐づくコメントデータを取得します。
- `usePostStore` と `useCommentStore` を使用して、投稿データとコメントデータを管理しています。

## バリデーション・エラーハンドリング
- 投稿データの取得中は `StatusInfo` コンポーネントが表示されます。
- 投稿データの取得に失敗した場合も `StatusInfo` コンポーネントが表示されます。
- コメント投稿時のバリデーションやエラーハンドリングは、`CreateComment` コンポーネントで行われます。

## 補足・制約
- 認証チェックが完了していない場合は、投稿データの取得をスキップしています。
- 投稿データの取得が完了した後、`currentPost` がnull になった場合は `StatusInfo` コンポーネントが表示されます。
