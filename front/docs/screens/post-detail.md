# 画面名
投稿詳細

# 必須構成

## 1. 画面概要
投稿の詳細情報を表示する画面です。投稿の内容、投稿者情報、コメント一覧、新規コメント投稿フォームが含まれています。

## 2. URL
`/posts/[id]`

## 3. フォーム項目・表示要素
- 投稿タイトル
- 投稿内容
- 投稿者アイコン
- 投稿者名
- 投稿日時
- カテゴリタグ一覧
- コメント一覧
- 新規コメント投稿フォーム

## 4. 初期表示・デフォルト値
- 投稿IDに対応する投稿データを取得し、画面に表示する
- コメント一覧は投稿IDに対応するコメントデータを取得し、表示する
- 新規コメント投稿フォームは初期状態で空の状態で表示する

## 5. ユーザー操作
- 投稿者アイコンをクリックすると、投稿者の投稿一覧ページに遷移する
- 「BACK」ボタンをクリックすると、前の画面に遷移する
- コメント一覧の下部にある新規コメント投稿フォームに入力し、送信ボタンをクリックすると、新規コメントが投稿される

## 6. バリデーション・エラーハンドリング
- 新規コメント投稿フォームの入力値に問題がある場合は、エラーメッセージを表示する
- 投稿データの取得や新規コメントの投稿に失敗した場合は、エラー画面を表示する

## 7. 画面遷移
- 投稿者アイコンをクリックすると、投稿者の投稿一覧ページ(`/?user=${投稿者名}`)に遷移する
- 「BACK」ボタンをクリックすると、前の画面に遷移する

## 8. 使用しているコンポーネント
- `PostDetail`: 投稿の詳細情報を表示するメインコンポーネント
- `TagList`: 投稿のカテゴリタグ一覧を表示するコンポーネント
- `Photo`: 投稿の画像を表示するコンポーネント
- `StatusInfo`: 読み込み中や、エラー時の状態を表示するコンポーネント
- `CommentsList`: 投稿に紐づくコメント一覧を表示するコンポーネント
- `CreateComment`: 新規コメント投稿フォームを表示するコンポーネント

## 9. 使用しているHooks / Stores / API / Schema
- `useParams`: URLパラメータからIDを取得するためのHook
- `usePostStore`: 投稿データの管理に使用するStore
- `useCommentStore`: コメントデータの管理に使用するStore
- `useRequireAuth`: ユーザー認証状態を確認するためのHook
- `fetchPost`: 投稿データを取得するためのAPI
- `fetchComments`: コメントデータを取得するためのAPI

## 10. 補足・制約
- 認証されていないユーザーがアクセスした場合は、ログインページに遷移する
- 投稿データや、コメントデータの取得に失敗した場合は、エラー画面を表示する
