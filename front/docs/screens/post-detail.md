# 画面名
投稿詳細

# 必須構成

## 1. 画面概要
投稿の詳細情報を表示する画面です。投稿の内容、投稿者情報、コメント一覧、新規コメント投稿フォームが含まれています。

## 2. URL
`/posts/:id`

## 3. フォーム項目・表示要素
- 投稿タイトル
- 投稿本文
- 投稿者アイコン
- 投稿者名
- 投稿日時
- カテゴリータグ一覧
- コメント一覧
- 新規コメント投稿フォーム

## 4. 初期表示・デフォルト値
- 投稿IDに対応する投稿データを取得し、画面に表示する
- 投稿に紐づくコメントデータを取得し、コメント一覧に表示する

## 5. ユーザー操作
- 投稿一覧ページへのリンクをクリックする
- コメント一覧の下部にある新規コメント投稿フォームからコメントを投稿する

## 6. バリデーション・エラーハンドリング
- 投稿データの取得に失敗した場合はエラー表示を行う
- コメント投稿時にバリデーションエラーが発生した場合はエラーメッセージを表示する

## 7. 画面遷移
- 投稿一覧ページ(`/`)へのリンクをクリックすると、投稿一覧ページに遷移する

## 8. 使用しているコンポーネント
- `Article`: 投稿の詳細情報を表示するメインコンポーネント
- `TagList`: 投稿のカテゴリータグ一覧を表示するコンポーネント
- `Photo`: 投稿の画像を表示するコンポーネント
- `CommentList`: 投稿に紐づくコメント一覧を表示するコンポーネント
- `CreateComment`: 新規コメント投稿フォームを表示するコンポーネント
- `StatusInfo`: 読み込み中やエラー時の状態を表示するコンポーネント

## 9. 使用しているHooks / Stores
- `useRequireAuth`: ユーザー認証状態を確認するカスタムフック
- `usePostStore`: 投稿データの管理に使用するストア
- `useCommentStore`: コメントデータの管理に使用するストア

## 10. 補足・制約
- 認証チェックが完了していない場合は、投稿データの取得をスキップする
- 投稿データの取得に失敗した場合はエラー表示を行う
- コメント投稿時にバリデーションエラーが発生した場合はエラーメッセージを表示する
- 画面遷移時に投稿データをリセットする
