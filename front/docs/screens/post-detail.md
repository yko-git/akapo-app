# 画面名
投稿詳細

# 必須構成

## 1. 画面概要
投稿の詳細情報を表示する画面です。投稿の内容、投稿者情報、コメント一覧、新規コメント投稿フォームが含まれています。

## 2. URL
`/posts/[id]`

## 3. フォーム項目・表示要素
- 投稿画像
- 投稿者アイコン
- 投稿者名
- 投稿日時
- カテゴリタグ一覧
- 投稿タイトル
- 投稿本文
- コメント一覧
- 新規コメント投稿フォーム

## 4. 初期表示・デフォルト値
- 投稿IDに対応する投稿データを取得し、画面に表示する
- コメント一覧は投稿IDに対応するコメントデータを取得し、表示する
- 新規コメント投稿フォームは初期状態で空の状態で表示される

## 5. ユーザー操作
- 投稿一覧ページへのリンクをクリックすると、投稿一覧ページに遷移する
- コメント一覧の下部にある新規コメント投稿フォームに入力し、送信ボタンをクリックすると、新規コメントが投稿される

## 6. バリデーション・エラーハンドリング
- 投稿データの取得に失敗した場合は、エラーメッセージを表示する
- コメントの投稿に失敗した場合は、エラーメッセージを表示する

## 7. 画面遷移
- 投稿一覧ページ(`/`)へのリンクが存在する

## 8. 使用しているコンポーネント
- `PostDetail`: 投稿の詳細情報を表示するメインコンポーネント
- `Photo`: 投稿画像を表示するコンポーネント
- `TagList`: 投稿のカテゴリタグ一覧を表示するコンポーネント
- `CommentsList`: 投稿に紐づくコメント一覧を表示するコンポーネント
- `CreateComment`: 新規コメント投稿フォームを表示するコンポーネント
- `StatusInfo`: 読み込み中やエラー時の状態を表示するコンポーネント

## 9. 使用しているHooks / Stores
- `usePostStore`: 投稿データの管理に使用
- `useCommentStore`: コメントデータの管理に使用
- `useRequireAuth`: ユーザー認証状態の管理に使用

## 10. 補足・制約
- ユーザーが認証されていない場合は、ログインページ(`/login`)に遷移する
- 投稿データの取得や新規コメントの投稿は非同期処理で行われる
