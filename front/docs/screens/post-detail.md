# 画面概要

投稿の詳細を表示する画面です。投稿の詳細情報と投稿に対するコメントの一覧、新規コメント投稿フォームが表示されます。

# URL

/posts/[id]

# 使用コンポーネント

- Article
  - Photo
  - TagList
  - CommentList
  - CreateComment
  - StatusInfo
  - Image

# フォーム項目・表示要素

- 投稿のタイトル
- 投稿の本文
- 投稿者のアイコンと名前
- 投稿の作成日
- 投稿のカテゴリー
- コメントの一覧
- 新規コメント投稿フォーム

# 初期表示・デフォルト値

- 初期表示時は、投稿ID（`[id]`）から投稿の詳細データを取得して表示する
- データの取得中は `StatusInfo` コンポーネントでローディング表示をする
- データの取得に失敗した場合は `StatusInfo` コンポーネントでエラー表示をする

# ユーザー操作

- 投稿一覧ページ（`/`）に戻るためのリンクを表示する
- コメントの一覧を表示する
- 新規コメントを投稿するためのフォームを表示する

# API連携

- `fetchPost` 関数を使用して、投稿ID（`[id]`）から投稿の詳細データを取得する
- `fetchComments` 関数を使用して、投稿ID（`postId`）からコメントの一覧データを取得する

# バリデーション・エラーハンドリング

- 投稿の取得に失敗した場合、`error` ステートに値が設定され、`StatusInfo` コンポーネントでエラー表示をする
