# 画面名
投稿詳細

# 必須構成

## 1. 画面概要
投稿の詳細情報を表示する画面です。投稿の内容、投稿者情報、コメント一覧、新規コメント投稿フォームが含まれています。

## 2. URL
`/posts/[id]`

## 3. フォーム項目・表示要素
- 投稿画像
- 投稿タイトル
- 投稿本文
- 投稿者名
- 投稿者アイコン
- 投稿カテゴリ
- 投稿日時
- コメント一覧
- 新規コメント投稿フォーム

## 4. 初期表示・デフォルト値
- 投稿IDに対応する投稿の詳細情報を取得して表示する
- コメント一覧は投稿IDに対応するコメントを取得して表示する
- 新規コメント投稿フォームは初期状態で空

## 5. ユーザー操作
- 投稿一覧ページへのリンクをクリックする
- コメント一覧を表示する
- 新規コメントを投稿する

## 6. バリデーション・エラーハンドリング
- 投稿の取得に失敗した場合はエラーメッセージを表示する
- 新規コメント投稿時のバリデーションエラーがあった場合はエラーメッセージを表示する

## 7. 画面遷移
- 投稿一覧ページ(`/`)へのリンクがある

## 8. 使用しているコンポーネント
- `PostDetail`: 投稿の詳細情報を表示するメインコンポーネント
- `TagList`: 投稿のカテゴリを表示するコンポーネント
- `Photo`: 投稿の画像を表示するコンポーネント
- `StatusInfo`: 読み込み中やエラー時の状態を表示するコンポーネント
- `CommentsList`: 投稿に紐づくコメントの一覧を表示するコンポーネント
- `CreateComment`: 新規コメントを投稿するフォームコンポーネント

## 9. 使用しているHooks / Stores / API / Schema
- `useParams`: URLパラメータからIDを取得するHook
- `usePostStore`: 投稿の状態を管理するStore
- `useCommentStore`: コメントの状態を管理するStore
- `useRequireAuth`: ユーザーの認証状態を確認するHook
- `fetchPost`: 投稿の詳細情報を取得するAPI
- `fetchComments`: 投稿に紐づくコメントを取得するAPI

## 10. 補足・制約
- 認証されていないユーザーはログインページ(`/login`)にリダイレクトされる
- 投稿の取得に失敗した場合はエラーメッセージを表示する
- コメントの投稿に失敗した場合はエラーメッセージを表示する
