# 画面仕様書

## 画面名
投稿詳細

## 必須構成

### 1. 画面概要
投稿の詳細情報を表示する画面です。投稿の本文、カテゴリ、投稿者情報、コメントの表示および入力が可能です。

### 2. URL
`/posts/:id`

### 3. フォーム項目・表示要素
- 投稿のタイトル
- 投稿の本文
- 投稿のカテゴリ
- 投稿者のアイコン画像
- 投稿者の名前
- 投稿日時
- コメントの一覧
- コメントの入力フォーム

### 4. 初期表示・デフォルト値
- 投稿詳細情報はサーバーから取得して初期表示する
- コメントの一覧もサーバーから取得して初期表示する
- コメントの入力フォームは初期状態で表示される

### 5. ユーザー操作
- 投稿一覧に戻るためのリンクをクリックする
- コメントの入力フォームにコメントを入力し、送信ボタンをクリックする

### 6. バリデーション・エラーハンドリング
- コメントの入力フォームのバリデーション
  - 必須入力
  - 最大文字数 (例: 1000文字)
- サーバー通信時のエラーハンドリング
  - 投稿の取得エラー
  - コメントの取得/投稿エラー
  - 適切なエラーメッセージの表示

### 7. 画面遷移
- 投稿一覧ページ(`/`)から本画面に遷移する
- 本画面からその他のページへの遷移はない

### 8. 使用しているコンポーネント
- `Article`: 投稿詳細の表示
- `TagList`: 投稿のカテゴリ表示
- `Photo`: 投稿の画像表示
- `CommentList`: コメントの一覧表示
- `CreateComment`: コメントの入力フォーム

### 9. 使用している Hooks / Stores
- `usePostStore`: 投稿の状態管理
- `useCommentStore`: コメントの状態管理
- `useRequireAuth`: ユーザー認証状態の確認

### 10. 補足・制約
- 認証されたユーザーのみがコメントを投稿できる
- 画像の表示サイズは固定
- レスポンシブデザイン対応
