# 画面概要
投稿の詳細ページです。投稿の内容と、その投稿に対するコメントを表示します。ユーザーは投稿に対してコメントを書くことができます。

# URL
`/posts/[id]`

# 使用コンポーネント
- `Article`: 投稿の詳細を表示するメインのコンポーネントです。
- `CommentList`: 投稿に対するコメントのリストを表示します。
- `CreateComment`: 投稿に対してコメントを作成するためのコンポーネントです。
- `StatusInfo`: 読み込み中や、エラー発生時に表示するステータス情報を表示します。
- `TagList`: 投稿のカテゴリーを表示します。
- `Photo`: 投稿の画像を表示します。
- `Image`: ユーザーのアイコン画像を表示します。

# フォーム項目・表示要素
- 投稿のタイトル
- 投稿の本文
- 投稿のカテゴリー
- 投稿の作成日時
- 投稿者のアイコンと名前
- コメントのリスト
- コメントの作成フォーム

# 初期表示・デフォルト値
- 投稿の詳細情報は、`fetchPost`関数を使ってAPIから取得します。
- コメントのリストは、`fetchComments`関数を使ってAPIから取得します。
- 読み込み中や、エラー発生時は`StatusInfo`コンポーネントで適切な状態を表示します。

# ユーザー操作
- ユーザーは「BACK」ボタンをクリックすることで、前のページに戻ることができます。
- ユーザーは投稿に対してコメントを書くことができます。

# API連携
- `fetchPost`関数を使って、投稿の詳細情報を取得します。
- `fetchComments`関数を使って、投稿に対するコメントのリストを取得します。

# バリデーション・エラーハンドリング
- 投稿の取得やコメントの取得でエラーが発生した場合は、`StatusInfo`コンポーネントでエラーメッセージを表示します。
- コメントの作成処理については、コード上では明確な実装が確認できませんでした。

# 補足・制約
- 認証状態によっては、投稿の取得やコメントの取得をスキップする処理が実装されています。
- 投稿の詳細情報やコメントのデータは、Storeを使って管理されています。
