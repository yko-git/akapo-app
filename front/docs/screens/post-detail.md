# 画面名
投稿詳細

# 必須構成

## 1. 画面概要
投稿の詳細情報を表示する画面です。投稿の内容、投稿者情報、コメント一覧、新規コメント投稿フォームが含まれています。

## 2. URL
`/posts/[id]`

## 3. フォーム項目・表示要素
- 投稿画像
- 投稿タイトル
- 投稿本文
- 投稿者名
- 投稿者アイコン
- 投稿カテゴリ
- 投稿日時
- コメント一覧
- 新規コメント投稿フォーム

## 4. 初期表示・デフォルト値
- 投稿IDに対応する投稿の詳細情報を取得して表示する
- コメント一覧は投稿IDに対応するコメントを取得して表示する
- 新規コメント投稿フォームは初期状態で空の状態で表示する

## 5. ユーザー操作
- 投稿一覧ページへのリンクをクリックする
- コメント一覧の中のコメントを閲覧する
- 新規コメント投稿フォームにコメントを入力し、送信ボタンをクリックする

## 6. バリデーション・エラーハンドリング
- 投稿の取得に失敗した場合はエラー表示を行う
- 新規コメント投稿時にコメント内容が空の場合はエラー表示を行う

## 7. 画面遷移
- 投稿一覧ページ(`/`)へのリンクがある

## 8. 使用しているコンポーネント
- `PostDetail`: 投稿の詳細情報を表示するメインコンポーネント
- `TagList`: 投稿のカテゴリを表示するコンポーネント
- `Photo`: 投稿の画像を表示するコンポーネント
- `StatusInfo`: 読み込み中やエラー時の状態を表示するコンポーネント
- `CreateComment`: 新規コメント投稿フォームを表示するコンポーネント
- `CommentsList`: コメント一覧を表示するコンポーネント

## 9. 使用しているHooks / Stores / API / Schema
- `useParams`: URLパラメータからIDを取得するためのHook
- `usePostStore`: 投稿の状態管理を行うStore
- `useCommentStore`: コメントの状態管理を行うStore
- `useRequireAuth`: ユーザー認証状態を確認するためのHook
- `fetchPost`: 投稿の詳細情報を取得するためのAPI
- `fetchComments`: 投稿に紐づくコメントを取得するためのAPI

## 10. 補足・制約
- ユーザーが認証されていない場合は、ログインページ(`/login`)にリダイレクトされる
- 投稿の取得に失敗した場合は、エラー表示を行う
- コメントの投稿に失敗した場合は、エラー表示を行う
