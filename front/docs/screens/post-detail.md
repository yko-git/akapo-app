# 画面仕様書

## 画面概要
投稿の詳細情報を表示する画面です。投稿の内容、コメント一覧、新規コメント投稿を行うことができます。

## URL
`/posts/:id`

## 使用コンポーネント
- `Article`: 投稿の詳細情報を表示するメインコンポーネントです。
- `TagList`: 投稿のカテゴリ一覧を表示するコンポーネントです。
- `Photo`: 投稿の画像を表示するコンポーネントです。
- `CommentList`: 投稿に対するコメントの一覧を表示するコンポーネントです。
- `CreateComment`: 新規コメントを投稿するためのフォームを提供するコンポーネントです。
- `StatusInfo`: ロード中や エラー発生時の表示を行うコンポーネントです。
- `Image`: Next.js の Image コンポーネントを使用して、ユーザーアイコンを表示しています。

## フォーム項目・表示要素
- 投稿のタイトル
- 投稿の本文
- 投稿者のアイコンと名前
- 投稿カテゴリの一覧
- 投稿日時
- コメントの一覧
- 新規コメントを投稿するためのフォーム

## 初期表示・デフォルト値
- 投稿IDを URL パラメータから取得し、対応する投稿データを API から取得して表示します。
- 投稿データの取得中は `StatusInfo` コンポーネントで "loading" 状態を表示します。
- 投稿データの取得に失敗した場合は `StatusInfo` コンポーネントで "service-down" 状態を表示します。

## ユーザー操作
- 投稿一覧ページ (ルートページ) にリンクするボタンがあります。
- 投稿に対するコメントを新規に投稿できます。

## API 連携
- `fetchPost` 関数を使用して、投稿IDに対応する投稿データを取得します。
- `fetchComments` 関数を使用して、投稿に対するコメントデータを取得します。

## バリデーション・エラーハンドリング
- 投稿データの取得中はローディング状態を表示します。
- 投稿データの取得に失敗した場合はエラー状態を表示します。
- コメントの新規投稿時のバリデーションとエラーハンドリングは `CreateComment` コンポーネントで行っています。

## 補足・制約
- 認証が完了していない場合は、投稿データの取得をスキップします。
- クリーンアップ関数で `currentPost` と `comments` をリセットしています。
- コード上で不明な点はありません。
