# 画面仕様書

## 画面概要
投稿編集画面では、投稿の詳細情報を表示し、編集することができます。投稿のタイトル、本文、ステータス、カテゴリ、画像を変更することができます。

## URL
`/posts/:id`

## 使用コンポーネント
- `PatchPost`: 投稿の編集を行うコンポーネント
- `Article`: 投稿の詳細情報を表示するコンポーネント
- `Button`: 投稿の編集を実行するボタン
- `SelectBox`: ステータスとカテゴリの選択ボックス
- `StatusInfo`: 投稿の取得状態を表示するコンポーネント

## フォーム項目・表示要素
- タイトル
- 本文
- ステータス
- カテゴリ
- 画像

## 初期表示・デフォルト値
- 投稿の詳細情報を取得し、フォームにデフォルト値を設定する
- 画像がある場合は、既存の画像のプレビューを表示する

## ユーザー操作
- タイトル、本文、ステータス、カテゴリを編集できる
- 新しい画像を選択できる
- 「投稿を編集する」ボタンを押すことで、編集内容を保存できる

## API連携
- `fetchPost`: 投稿の詳細情報を取得する
- `patchPost`: 投稿を編集する
- `uploadImage`: 新しい画像をアップロードする

## バリデーション・エラーハンドリング
- 画像ファイルは`validateImageFile`関数でバリデーションを行う
- 編集の際にエラーが発生した場合は、エラーメッセージを表示する

## 補足・制約
- 既存の画像がある場合、新しい画像を選択しない限り既存の画像が保持される
- コード上では、投稿の取得に失敗した場合のエラー処理が記述されていない
