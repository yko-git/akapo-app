# 画面名
投稿編集

# 必須構成

## 1. 画面概要
投稿の編集を行う画面です。既存の投稿の情報を表示し、ユーザーが必要に応じて編集を行うことができます。

## 2. URL
/posts/new/[id]

## 3. フォーム項目・表示要素
- タイトル
- 本文
- ステータス
- カテゴリー
- 画像

## 4. 初期表示・デフォルト値
- 既存の投稿の情報が初期値として表示される
- ステータスのデフォルト値は「0」
- カテゴリーのデフォルト値は「1」

## 5. ユーザー操作
- タイトル、本文、ステータス、カテゴリーの編集
- 画像の変更

## 6. バリデーション・エラーハンドリング
- タイトルと本文は必須入力
- 画像ファイルのバリデーション（サイズ、形式など）
- エラー発生時はエラーメッセージを表示

## 7. 画面遷移
- 投稿一覧画面に遷移できる

## 8. 使用しているコンポーネント
- PatchPost
- Button
- SelectBox
- StatusInfo

## 9. 使用しているHooks / Stores / API / Schema
- usePostForm
- patchPost
- uploadImage
- fetchPost
- NewPost
- NewPostSchema

## 10. 補足・制約
- 既存の画像が存在する場合は、それを初期表示する
- 新しい画像を選択しない場合は、既存の画像が保持される
- 投稿の更新に成功した場合は、マイページに遷移する
