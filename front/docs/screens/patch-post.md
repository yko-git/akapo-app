# 画面概要
投稿の編集画面です。ユーザーは投稿のタイトル、本文、ステータス、カテゴリ、画像を編集できます。

# URL
`/posts/{id}`

# 使用コンポーネント
- `PatchPost`: 投稿編集のメインフォームを提供するコンポーネント
- `Button`: フォームの送信ボタンに使用
- `SelectBox`: ステータスとカテゴリの選択に使用
- `StatusInfo`: 読み込み中や エラー時の表示に使用
- `imageCompression`: 画像の圧縮に使用
- `validateImageFile`: 画像ファイルのバリデーションに使用

# フォーム項目・表示要素
- タイトル
- 本文
- ステータス
- カテゴリ
- 画像

# 初期表示・デフォルト値
- 既存の投稿情報が初期値として表示される
- 既存の画像がプレビューとして表示される

# ユーザー操作
1. タイトル、本文、ステータス、カテゴリを編集できる
2. 新しい画像を選択できる
3. 「投稿を編集する」ボタンをクリックして編集を確定できる

# API連携
- `fetchPost`: 既存の投稿情報を取得する
- `patchPost`: 投稿を更新する
- `uploadImage`: 画像をアップロードする

# バリデーション・エラーハンドリング
- タイトル、本文のバリデーションを行う
- 画像ファイルのバリデーションを行う
- エラー発生時はToastで表示する

# 補足・制約
- コード上では、画像の圧縮オプションが定数 `IMAGE_COMPRESSION_OPTIONS` で定義されているが、その内容は不明
- 画像の更新は任意で、更新しない場合は既存の画像が保持される
