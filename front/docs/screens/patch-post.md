# 画面仕様書

## 画面概要
投稿を編集する画面です。既存の投稿の情報を読み込み、編集可能な項目を表示し、投稿内容の更新が可能です。

## URL
`/posts/:id`

## 使用コンポーネント
- `PatchPost`: 投稿編集機能を提供するメインコンポーネントです。
- `Button`: 投稿を編集するためのボタンコンポーネントです。
- `SelectBox`: カテゴリとステータスの選択用のドロップダウンコンポーネントです。
- `StatusInfo`: 読み込み中や投稿が見つからない場合の表示用コンポーネントです。

## フォーム項目・表示要素
- タイトル
- 本文
- ステータス
- カテゴリ
- 画像

## 初期表示・デフォルト値
- 既存の投稿の情報がページにロードされ、以下の項目が表示されます:
  - タイトル
  - 本文
  - ステータス
  - カテゴリ
  - 既存の画像

## ユーザー操作
- タイトル、本文、ステータス、カテゴリを編集可能
- 新しい画像をアップロードできる
- 「投稿を編集する」ボタンをクリックすると、投稿内容が更新される

## API連携
- `fetchPost`: 投稿の詳細情報を取得するAPI
- `patchPost`: 投稿を更新するAPI
- `uploadImage`: 画像をアップロードするAPI

## バリデーション・エラーハンドリング
- タイトルと本文は必須項目です
- 画像ファイルのバリデーションが行われ、サポートされている形式（PNG、JPEG、WEBP、SVG）のみ許可されます
- エラーが発生した場合はToastで通知されます

## 補足・制約
- コード上では、画像の既存のURLが `post.signedUrl` から取得されています
- 画像はブラウザ側で圧縮されてから、アップロードされます
- 既存の画像が選択されていない場合は、前の画像が保持されます
