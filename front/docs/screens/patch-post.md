# 画面名
投稿編集

# 必須構成

## 1. 画面概要
投稿の編集を行う画面です。既存の投稿の情報を表示し、タイトル、本文、ステータス、カテゴリー、画像の編集が可能です。

## 2. URL
/posts/[id]

## 3. フォーム項目・表示要素
- タイトル
- 本文
- ステータス
- カテゴリー
- 画像

## 4. 初期表示・デフォルト値
- 既存の投稿の情報が初期表示されます。
- ステータスのデフォルト値は投稿の現在のステータスが選択されています。
- カテゴリーのデフォルト値は投稿に紐づいているカテゴリーが選択されています。
- 既存の画像がプレビューとして表示されます。

## 5. ユーザー操作
- タイトル、本文、ステータス、カテゴリーを編集できます。
- 新しい画像をアップロードできます。
- 「投稿を編集」ボタンをクリックすると、投稿の更新が行われます。

## 6. バリデーション・エラーハンドリング
- タイトルと本文は必須入力項目です。
- 画像ファイルは PNG、JPEG、WEBP、SVG のいずれかのファイル形式である必要があります。
- 投稿の更新に失敗した場合はエラーメッセージを表示します。

## 7. 画面遷移
- 投稿の更新が完了すると、マイページ(/mypage)に遷移します。

## 8. 使用しているコンポーネント
- Button
- SelectBox
- StatusInfo

## 9. 使用しているHooks / Stores
- usePostForm
- useRouter

## 10. 補足・制約
- 画像の圧縮処理を行っています。
- 既存の画像が存在する場合は、それを初期表示します。
