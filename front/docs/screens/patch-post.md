# 画面名
投稿編集

# 必須構成

## 1. 画面概要
投稿の編集を行うための画面です。既存の投稿の情報を表示し、ユーザーが必要に応じて編集を行うことができます。

## 2. URL
`/posts/new/[id]`

## 3. フォーム項目・表示要素
- タイトル
- 本文
- ステータス
- カテゴリー
- 画像

## 4. 初期表示・デフォルト値
- 既存の投稿の情報が初期値として表示されます。
- ステータスのデフォルト値は「0」、カテゴリーのデフォルト値は「1」が設定されています。

## 5. ユーザー操作
- タイトル、本文、ステータス、カテゴリーを編集することができます。
- 画像を新しいものに変更することができます。
- 「投稿を編集」ボタンをクリックすると、編集内容が保存されます。
- 「投稿一覧に戻る」ボタンをクリックすると、投稿一覧画面に遷移します。

## 6. バリデーション・エラーハンドリング
- タイトルと本文は必須入力項目です。
- 画像ファイルは指定のファイル形式（PNG、JPEG、WebP、SVG）のみ許可されます。
- 入力エラーが発生した場合は、エラーメッセージが表示されます。
- 投稿の更新に失敗した場合は、エラーメッセージが表示されます。

## 7. 画面遷移
- 「投稿一覧に戻る」ボタンをクリックすると、投稿一覧画面(`/`)に遷移します。

## 8. 使用している コンポーネント
- `PatchPost`: 投稿の編集フォームを提供するコンポーネント
- `Button`: ボタンコンポーネント
- `SelectBox`: ドロップダウンリストコンポーネント
- `StatusInfo`: ローディング状態やエラー状態を表示するコンポーネント

## 9. 使用している Hooks / Stores
- `usePostForm`: 投稿フォームの状態管理と入力値のバリデーションを行うカスタムフック
- `useParams`: URLパラメータを取得するフック
- `useRouter`: ページ遷移を行うフック

## 10. 補足・制約
- 画像の圧縮処理を行っています。
- 既存の画像が存在する場合は、それを初期表示します。
