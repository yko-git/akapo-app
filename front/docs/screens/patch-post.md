# 画面名
投稿編集

# 必須構成

## 1. 画面概要
投稿の編集を行う画面です。既存の投稿の情報を表示し、ユーザーが必要に応じて編集を行うことができます。

## 2. URL
`/posts/:id/edit`

## 3. フォーム項目・表示要素
- タイトル
- 本文
- ステータス
- カテゴリー
- 画像

## 4. 初期表示・デフォルト値
- 既存の投稿の情報が初期値として表示される
- 画像は既存の画像がプレビューとして表示される

## 5. ユーザー操作
- タイトル、本文、ステータス、カテゴリーを編集できる
- 新しい画像をアップロードできる
- 「投稿を編集」ボタンをクリックすると、投稿の更新が行われる

## 6. バリデーション・エラーハンドリング
- タイトルと本文は必須入力
- 画像ファイルは指定のファイル形式（PNG、JPEG、WEBP、SVG）のみ許可される
- 入力エラーがある場合はエラーメッセージを表示する
- 投稿の更新に失敗した場合はエラーメッセージを表示する

## 7. 画面遷移
- 投稿の編集が完了すると、マイページ（`/mypage`）に遷移する

## 8. 使用しているコンポーネント
- `Button`
- `SelectBox`
- `StatusInfo`

## 9. 使用しているHooks / Stores
- `usePostForm`
- `useRouter`

## 10. 補足・制約
- 画像の圧縮処理を行っている
- 既存の画像が存在する場合は、それを初期表示する
