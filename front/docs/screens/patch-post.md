# 画面名
投稿編集

# 必須構成

## 1. 画面概要
投稿の編集を行うための画面です。投稿の詳細情報を表示し、タイトル、本文、ステータス、カテゴリーの編集、画像の変更が可能です。

## 2. URL
/posts/new/[id]

## 3. フォーム項目・表示要素
- タイトル
- 本文
- ステータス
- カテゴリー
- 画像

## 4. 初期表示・デフォルト値
- 既存の投稿の情報が初期表示されます。
- ステータスのデフォルト値は「0」、カテゴリーのデフォルト値は「1」が設定されています。

## 5. ユーザー操作
- タイトル、本文、ステータス、カテゴリーの編集が可能です。
- 画像の変更が可能です。
- 「投稿を編集」ボタンをクリックすると、投稿の更新が行われます。
- 「投稿一覧に戻る」ボタンをクリックすると、投稿一覧ページに遷移します。

## 6. バリデーション・エラーハンドリング
- タイトルと本文は必須入力項目です。
- 画像ファイルのバリデーションを行っています。
- エラー発生時はトーストメッセージで通知されます。

## 7. 画面遷移
- 「投稿一覧に戻る」ボタンをクリックすると、投稿一覧ページ(/mypage)に遷移します。

## 8. 使用しているコンポーネント
- PatchPost
- Button
- SelectBox
- StatusInfo

## 9. 使用しているHooks / Stores
- usePostForm
- useParams
- useRouter

## 10. 補足・制約
- 既存の画像が存在する場合は、新しい画像を選択しない限り既存の画像が保持されます。
- 画像の圧縮処理が行われます。
