# 画面名
投稿編集

# 必須構成

## 1. 画面概要
投稿の編集を行うための画面です。投稿のタイトル、本文、ステータス、カテゴリーの変更や、新しい画像のアップロードが可能です。

## 2. URL
/posts/new/[id]

## 3. フォーム項目・表示要素
- タイトル
- 本文
- ステータス
- カテゴリー
- 画像

## 4. 初期表示・デフォルト値
- 既存の投稿の情報が初期値として表示される
- 画像は既存の画像がプレビューとして表示される

## 5. ユーザー操作
- タイトル、本文、ステータス、カテゴリーの編集
- 新しい画像のアップロード
- 投稿の編集を実行するボタンをクリック

## 6. バリデーション・エラーハンドリング
- タイトルと本文は必須入力
- 画像ファイルは指定のファイル形式（PNG、JPEG、WebP、SVG）のみ許可
- 入力エラーが発生した場合はエラーメッセージを表示
- 投稿の編集に失敗した場合はエラーメッセージを表示

## 7. 画面遷移
- 投稿一覧画面に遷移できるリンクが用意されている

## 8. 使用しているコンポーネント
- PatchPost
- Button
- SelectBox
- StatusInfo

## 9. 使用しているHooks / Stores
- usePostForm
- useParams
- useRouter

## 10. 補足・制約
- 既存の画像は圧縮して再アップロードされる
- 新しい画像を選択しない場合は、既存の画像が保持される
