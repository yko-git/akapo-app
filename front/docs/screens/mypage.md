# 画面概要
マイページ画面では、ログイン中のユーザーの基本情報(名前、アイコン)と、ユーザーが投稿した記事の一覧が表示されます。また、新しい投稿を作成したり、ログアウトすることができます。

# URL
- `/mypage`

# 使用コンポーネント
- `UserPage`
  - `UserArticleList`
  - `Button`
  - `StatusInfo`
  - `Image`

# フォーム項目・表示要素
- ユーザー名
- ユーザーアイコン
- 投稿一覧

# 初期表示・デフォルト値
- ユーザー情報を取得中は「ユーザー情報を読み込んでいます...」と表示される
- ユーザー情報の取得に失敗した場合は、エラーメッセージが表示される

# ユーザー操作
- 新しい投稿を作成する
  - `/posts/new` へ遷移
- ログアウトする
  - ログアウト処理を実行し、/login へ遷移

# API連携
- `fetchUserData()`: ユーザーの基本情報を取得する
- `fetchUserPosts()`: ユーザーが投稿した記事の一覧を取得する

# バリデーション・エラーハンドリング
- ユーザー情報の取得に失敗した場合、エラーメッセージが表示される

# 補足・制約
- コード上では、ユーザー認証の状態を管理する `useRequireAuth` フックが使用されているが、その実装は不明
