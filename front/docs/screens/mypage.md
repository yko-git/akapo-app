# 画面名
マイページ

# 画面概要
ユーザーの個人情報とユーザーが投稿した記事の一覧を表示する画面です。ログアウト機能と新規投稿ボタンも備えています。

# URL
/mypage

# フォーム項目・表示要素
- ユーザーのアイコン画像
- ユーザー名
- ログアウトボタン
- 新規投稿ボタン
- ユーザーの投稿一覧

# 初期表示・デフォルト値
- ユーザー情報の読み込み中は「ユーザー情報を読み込み中...」と表示する
- ユーザー情報の取得に失敗した場合は「投稿の取得に失敗しました」と表示する

# ユーザー操作
- ログアウトボタンをクリックするとログアウトし、ログイン画面に遷移する
- 新規投稿ボタンをクリックすると新規投稿画面に遷移する

# バリデーション・エラーハンドリング
- ユーザー情報の取得に失敗した場合はエラーメッセージを表示する

# 画面遷移
- ログアウトボタンをクリックすると、ログイン画面(/login)に遷移する
- 新規投稿ボタンをクリックすると、新規投稿画面(/posts/new)に遷移する

# 使用しているコンポーネント
- UserPage
- UserArticleList
- Button
- StatusInfo
- Image

# 使用しているHooks / Stores
- useRequireAuth
- usePostStore
- useAuthStore

# 補足・制約
- ユーザー認証が必要な画面です
- ユーザー情報とユーザーの投稿一覧は非同期で取得します
