# 画面名
マイページ

# 画面概要
ユーザーの個人情報とユーザーが投稿した記事の一覧を表示するページです。ログアウト機能と新規投稿ボタンも備えています。

# URL
/mypage

# フォーム項目・表示要素
- ユーザーのアイコン画像
- ユーザーの名前
- ユーザーが投稿した記事の一覧

# 初期表示・デフォルト値
- ユーザーのアイコン画像とユーザー名は、ユーザーデータの取得が完了するまで「ユーザー情報を読み込み中です...」と表示される
- ユーザーが投稿した記事の一覧は、記事データの取得が完了するまで空の状態で表示される

# ユーザー操作
- ログアウトボタンをクリックするとログアウトし、ログイン画面に遷移する
- 「新しい投稿を作成」ボタンをクリックすると、新規投稿ページ(/posts/new)に遷移する

# バリデーション・エラーハンドリング
- ユーザーデータや投稿データの取得に失敗した場合は、エラーメッセージを表示する

# 画面遷移
- ログアウトボタンをクリックすると、ログイン画面(/login)に遷移する
- 「新しい投稿を作成」ボタンをクリックすると、新規投稿ページ(/posts/new)に遷移する

# 使用しているコンポーネント
- UserPage
- UserArticleList
- Button
- StatusInfo
- Image

# 使用しているHooks / Stores
- useRequireAuth
- usePostStore
- useAuthStore

# 補足・制約
- ユーザーがログインしていない場合は、ログイン画面に遷移する
- ユーザーデータや投稿データの取得に失敗した場合は、エラーメッセージを表示する
