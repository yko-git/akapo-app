# マイページ

## 画面概要
このページはユーザーのプロフィールと投稿一覧を表示する画面です。

## URL
- `/mypage`

## 使用コンポーネント
- `UserPage`
- `UserArticleList`
- `Button`
- `StatusInfo`
- `Image`

## フォーム項目・表示要素
- ユーザーのプロフィール情報
  - ユーザーアイコン
  - ユーザー名
- ログアウトボタン
- 新規投稿作成ボタン
- ユーザーの投稿一覧

## 初期表示・デフォルト値
- ユーザー情報の読み込み中は「ユーザー情報を読み込んでいます...」と表示する
- ユーザー情報の取得に失敗した場合は、エラーメッセージを表示する

## ユーザー操作
- ログアウトボタンをクリックするとログアウトし、ログイン画面に遷移する
- 新規投稿作成ボタンをクリックすると、新規投稿作成ページに遷移する

## API連携
- `fetchUserData` API を呼び出してユーザーデータを取得する
- `fetchUserPosts` API を呼び出してユーザーの投稿データを取得する

## バリデーション・エラーハンドリング
- ユーザーデータの取得に失敗した場合は、エラーメッセージを表示する
- 投稿データの取得に失敗した場合は、エラーメッセージを表示する

## 補足・制約
- コード上では、ユーザーが認証済みかどうかのチェックが行われている (`useRequireAuth` フック)
- ログアウト処理は `useAuthStore` のロジックを使用している
