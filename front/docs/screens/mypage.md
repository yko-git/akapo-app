# 画面名
マイページ

# 必須構成

## 1. 画面概要
ユーザーの個人情報とユーザーが投稿した記事の一覧を表示する画面です。ログアウト機能と新規投稿ボタンも備えています。

## 2. URL
/mypage

## 3. フォーム項目・表示要素
- ユーザーのアイコン画像
- ユーザーの名前
- ログアウトボタン
- 新規投稿ボタン
- ユーザーの投稿一覧

## 4. 初期表示・デフォルト値
- ユーザー情報とユーザーの投稿一覧を初期表示する
- ユーザー情報の読み込み中は "ユーザー情報を読み込み中です..." と表示する

## 5. ユーザー操作
- ログアウトボタンをクリックするとログアウトし、ログイン画面に遷移する
- 新規投稿ボタンをクリックすると新規投稿画面に遷移する
- ユーザーの投稿一覧を表示する

## 6. バリデーション・エラーハンドリング
- ユーザー情報の取得に失敗した場合は "投稿の取得に失敗しました" と表示する
- ユーザー情報の取得中は "ロード中" の状態を表示する

## 7. 画面遷移
- ログアウトボタンをクリックすると、ログイン画面(/login)に遷移する
- 新規投稿ボタンをクリックすると、新規投稿画面(/posts/new)に遷移する

## 8. 使用しているコンポーネント
- `Button`: ログアウトボタンと新規投稿ボタンに使用
- `StatusInfo`: ユーザー情報の取得状態を表示
- `Image`: ユーザーのアイコン画像を表示
- `UserPostListPage`: ユーザーの投稿一覧を表示

## 9. 使用しているHooks / Stores
- `useAuthStore`: ユーザー情報の管理
- `usePostStore`: 投稿情報の管理
- `useRequireAuth`: 認証状態の確認

## 10. 補足・制約
- ユーザーがログインしていない場合は、ログイン画面に遷移する
- ユーザー情報の取得に失敗した場合は、エラーメッセージを表示する
