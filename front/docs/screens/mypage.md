# 画面名
マイページ

# 必須構成

## 1. 画面概要
ユーザーの個人情報や投稿一覧を表示するページです。ログアウト機能も提供しています。

## 2. URL
/mypage

## 3. フォーム項目・表示要素
- ユーザーのアイコン画像
- ユーザー名
- ログアウトボタン
- 新規投稿ボタン
- 投稿一覧

## 4. 初期表示・デフォルト値
- ユーザー情報の読み込み中は「ユーザー情報を読み込み中です...」と表示する
- ログアウト中は「ログアウト」ボタンが表示される

## 5. ユーザー操作
- ログアウトボタンをクリックするとログアウトし、ログインページ(/login)に遷移する
- 新規投稿ボタンをクリックすると新規投稿ページ(/posts/new)に遷移する

## 6. バリデーション・エラーハンドリング
- ユーザー情報の取得に失敗した場合は「投稿の取得に失敗しました」と表示する
- 投稿一覧の取得中は「ローディング中」と表示する

## 7. 画面遷移
- ログアウトボタンをクリックすると、ログインページ(/login)に遷移する
- 新規投稿ボタンをクリックすると、新規投稿ページ(/posts/new)に遷移する

## 8. 使用しているコンポーネント
- UserPage
- UserArticleList
- Button
- StatusInfo
- Image

## 9. 使用しているHooks / Stores
- useRequireAuth
- usePostStore
- useAuthStore

## 10. 補足・制約
- ログイン状態でのみアクセス可能
- ユーザー情報とユーザーの投稿一覧を非同期で取得する
