# 画面名
マイページ

# 必須構成

## 1. 画面概要
ユーザーの個人情報や投稿一覧を表示するページです。ログアウト機能も提供されています。

## 2. URL
/mypage

## 3. フォーム項目・表示要素
- ユーザーのアイコン画像
- ユーザー名
- ログアウトボタン
- 新規投稿ボタン
- 投稿一覧

## 4. 初期表示・デフォルト値
- ユーザー情報の読み込み中は、ローディング表示が表示されます。
- ユーザー情報の取得に失敗した場合は、エラー表示が表示されます。

## 5. ユーザー操作
- ログアウトボタンをクリックするとログアウトし、/mypage に遷移します。
- 新規投稿ボタンをクリックすると、新規投稿ページ(/posts/new)に遷移します。

## 6. バリデーション・エラーハンドリング
- ユーザー情報の取得に失敗した場合は、エラーメッセージが表示されます。

## 7. 画面遷移
- ログアウトボタンをクリックすると、/mypage に遷移します。
- 新規投稿ボタンをクリックすると、/posts/new に遷移します。

## 8. 使用しているコンポーネント
- UserPage
- UserArticleList
- Button
- StatusInfo
- Image

## 9. 使用しているHooks / Stores
- useRequireAuth
- usePostStore
- useAuthStore

## 10. 補足・制約
- ユーザー認証が必要です。未ログインの場合は、ログイン画面に遷移します。
- ユーザー情報の取得に失敗した場合は、エラー表示が表示されます。
