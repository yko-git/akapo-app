# 画面名
Profile

# 必須構成

## 1. 画面概要
このページは、ユーザーのプロフィールを表示する画面です。ユーザーの基本情報や経歴、スキルなどが確認できます。

## 2. URL
/profile

## 3. フォーム項目・表示要素
- ユーザーの写真
- 住まい
- 自己紹介
- 使用言語
- 使用ツール
- 経歴

## 4. 初期表示・デフォルト値
- ユーザーの写真、住まい、自己紹介、使用言語、使用ツール、経歴が初期表示されます。

## 5. ユーザー操作
- このページはユーザー操作を必要としません。閲覧のみの画面です。

## 6. バリデーション・エラーハンドリング
- バリデーションやエラーハンドリングは行われていません。

## 7. 画面遷移
- このページは単独の画面であり、他の画面との遷移は定義されていません。

## 8. 使用しているコンポーネント
- Image
- jost (フォントコンポーネント)

## 9. 使用しているHooks / Stores
- 使用しているHooksやStoreはありません。

## 10. 補足・制約
- 特に制約はありません。
