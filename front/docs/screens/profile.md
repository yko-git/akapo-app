# 画面名
Profile

# 必須構成

## 1. 画面概要
このページは、ユーザーのプロフィールを表示する画面です。ユーザーの基本情報や経歴、スキルなどが確認できます。

## 2. URL
/profile

## 3. フォーム項目・表示要素
- ユーザー画像
- 住まい
- 自己紹介
- 言語
- 使用ツール
- 経歴

## 4. 初期表示・デフォルト値
- ユーザー画像は固定の画像が表示されます。
- その他の情報は、コンポーネントに直接記述された値が表示されます。

## 5. ユーザー操作
このページにはユーザー操作はありません。ページ内の情報を閲覧するのみです。

## 6. バリデーション・エラーハンドリング
このページにはバリデーションやエラーハンドリングはありません。

## 7. 画面遷移
このページから他の画面への遷移はありません。

## 8. 使用しているコンポーネント
- Image (next/image)
- jost (フォントコンポーネント)

## 9. 使用しているHooks / Stores / API / Schema
特に使用していません。

## 10. 補足・制約
特になし
