# 画面名
Profile

# 必須構成

## 1. 画面概要
このページは、ユーザーのプロフィールを表示する画面です。ユーザーの基本情報や経歴、スキルなどが確認できます。

## 2. URL
/profile

## 3. フォーム項目・表示要素
- ユーザーの画像
- 住まい
- 自己紹介
- 使用言語
- 使用ツール
- 経歴

## 4. 初期表示・デフォルト値
- ユーザーの画像、住まい、自己紹介、使用言語、使用ツール、経歴が初期表示されます。
- デフォルト値はありません。

## 5. ユーザー操作
- このページはユーザーが閲覧するだけの画面で、ユーザー操作はありません。

## 6. バリデーション・エラーハンドリング
- バリデーションやエラーハンドリングは行われていません。

## 7. 画面遷移
- このページは単独の画面で、他の画面への遷移はありません。

## 8. 使用しているコンポーネント
- Image
- jost (フォントコンポーネント)

## 9. 使用しているHooks / Stores
- 使用しているHooks/Storesはありません。

## 10. 補足・制約
- 画像の表示サイズは固定されています。
- 自己紹介の文章は複数行で表示されます。
- 言語やツールの一覧は、改行なしで表示されます。
