## ADR を追加する

新しい設計判断を記録する場合は、ADR を追加する。

命名規則:

```text
0002-authentication-strategy.md
0003-directory-structure.md
```

---

## ADR として残すもの

以下のような「将来的に判断理由を参照したくなるもの」を記録する。

- アーキテクチャに影響する意思決定
- 技術選定の理由
- ディレクトリ構成や設計方針
- 認証・状態管理・API設計などの方針
- 採用しなかった選択肢と理由

---

## ADR として残さないもの

以下は ADR ではなく、Issue やメモで管理する。

- 一時的な作業メモ
- 軽微なUI変更
- 実装手順のみの記録
- 単なるタスク管理
