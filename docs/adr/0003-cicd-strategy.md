# 0003-cicd-strategy

GitHub Actions を利用した CI/CD 構成を採用

## 適用範囲

本プロジェクトのビルド・テスト・デプロイ・ドキュメント生成に適用する

## 背景

Frontend / Backend を継続的に安全にデプロイし、手動作業によるミスを減らしたい。

以下を継続的に自動化したい

- デプロイ
- ビルド確認
- ドキュメント生成
- EC2起動

## 選択肢

### 手動デプロイ

- 手軽
- ミスが発生しやすい
- 運用に向かない

### GitHub Actions

- GitHubと統合しやすい
- 自動化を行いやすい
- GitHub Actions から EC2 操作や Vercel デプロイを自動化しやすい

## 決定

GitHub Actions を利用した CI/CD 構成を採用

## 理由

- デプロイ作業を自動化したい
- AI仕様書生成フローを統合したい
- GitHub中心で運用を統一したい
- EC2の起動・停止を自動化し、運用負荷を軽減したい

## トレードオフ

- Workflow管理コストが発生する
- デプロイ障害につながる可能性がある
