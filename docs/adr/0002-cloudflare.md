# 0002-cloudflare

Cloudflare経由構成を採用

## 適用範囲

本プロジェクトのDNS・CDN（データをキャッシュすることで、コンテンツ（S3）へのアクセスを高速化できる）・外部公開経路に提要する

## 背景

DNS管理・CDN・HTTPS・セキュリティを統一的に管理したい

## 選択肢

### Route53のみ

- シンプルなDNS管理＝機能が限定的
- AWSと親和性が高い

### Cloudflare + Route53

- Cloudflareをプロキシ（内部ネットワークにあるコンピュータのアクセスを中継し、代理でインターネットへ接続を行うコンピュータ）として利用
- Route53をドメイン管理に利用
- CDNを利用できる
- DNS管理を一元化しやすい
- Cloudflare障害時の影響を受ける

## 決定

Cloudflare経由構成を採用

## 理由

- DNS/CDN/HTTPSを統一的に管理できる
- CDNによる最適化を行える

## トレードオフ

- インフラ構成が複雑
